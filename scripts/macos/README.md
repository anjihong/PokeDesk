# DeskPokemon for macOS

`DeskPokemon.app`을 일정한 위치(예: Applications)에 두고 실행하세요.
Dock에 표시되지 않는 데스크톱 펫이며, 포켓몬의 우클릭 메뉴에서 종료할 수 있습니다.

다른 앱을 사용하는 동안 키 입력·마우스 클릭에 맞춰 포켓몬이 반응하고 경험치를 얻으려면
macOS **시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링**에서 DeskPokemon을 허용하세요.
권한을 변경한 뒤 앱을 완전히 종료하고 다시 실행하세요. 입력 문자열은 저장하거나 전송하지 않습니다.
허용하지 않아도 포켓몬 선택, 도감, 알 등 앱 화면을 사용할 수 있습니다.
개발 중 터미널에서 실행하면 권한 대상이 터미널 또는 dotnet 호스트로 표시될 수 있으므로
최종 확인은 `.app`으로 실행해서 진행하세요.

이 패키징 스크립트는 로컬 테스트용 ad-hoc 서명을 적용합니다.
Apple Developer ID로 서명하거나 공증한 배포본은 아닙니다.
다운로드한 테스트 빌드가 차단되면 출처를 확인한 후 macOS 개인정보 보호 및 보안의
앱 실행 허용 절차를 따르세요. 공개 배포 전에는 Developer ID 서명과 공증이 필요합니다.
