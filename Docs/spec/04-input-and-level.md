# 입력 경험치와 레벨

- Windows 저수준 훅으로 전역 키 누름과 마우스 왼쪽·오른쪽·가운데 버튼 누름을 감지한다. 마우스 이동은 세지 않는다.
- 같은 키를 누른 채 발생하는 자동 반복은 입력으로 중복 계산하지 않는다. 키를 놓았다가 다시 누르면 새 입력으로 계산한다.
- 입력 1회당 현재 선택 포켓몬의 경험치가 1 증가한다. 다음 레벨에 필요한 경험치는 `현재 레벨 × 30`이다. 레벨업 시 필요한 경험치를 차감하고 레벨을 1 올리며 레벨 표시를 강조한다.
- 누적 입력 10,000회 기준 `Lv.26`, 경험치 `250/780`이 된다.
- 레벨과 경험치는 도감 번호와 일반·이로치 색상별로 따로 저장된다. 같은 종의 일반 개체와 이로치는 성장 상태를 공유하지 않는다.
- 변경 사항은 5초 주기로 저장하며, 창이 닫힐 때도 저장한다.
