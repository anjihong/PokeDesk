# 입력 경험치와 레벨

## 입력 감지

Windows 저수준 전역 훅을 사용하므로 DeskPokemon 창이 활성 상태가 아니어도 입력을 센다.

| 입력 | 경험치 반영 |
| --- | --- |
| 일반 키 누름 | 1회 |
| `Alt` 등 시스템 키 누름 | 1회 |
| 누른 키의 자동 반복 | 최초 1회만 |
| 키를 놓은 뒤 다시 누름 | 새 입력 1회 |
| 마우스 왼쪽·오른쪽·가운데 버튼 누름 | 각 1회 |
| 마우스 이동·휠 | 반영하지 않음 |

키 자동 반복은 현재 눌린 가상 키 목록으로 차단한다. 앱 종료 시 키보드·마우스 훅을 해제한다.

## 경험치 규칙

- 입력 1회당 현재 선택된 `도감 번호 + 일반/이로치` 개체의 경험치가 1 증가한다.
- 레벨 `n`에서 다음 레벨까지 필요한 경험치는 `30 × n`이다.
- 레벨업 시 요구 경험치를 차감하고 레벨을 1 올린다. 초과 경험치는 다음 레벨 진행도로 남는다.
- 레벨 1에서 레벨 `L`에 도달하는 누적 경험치는 `15 × (L - 1) × L`이다.

| 현재 레벨 | 다음 레벨 요구 경험치 | 해당 레벨까지 누적 경험치 |
| ---: | ---: | ---: |
| 1 | 30 | 0 |
| 2 | 60 | 30 |
| 5 | 150 | 300 |
| 10 | 300 | 1,350 |
| 26 | 780 | 9,750 |

누적 입력 10,000회면 `Lv.26`, 경험치 `250/780`이다.

## 개체별 성장

- 도감 번호별 성장 상태를 따로 저장한다.
- 같은 종의 일반과 이로치도 성장 상태를 공유하지 않는다.
- 도감에서 포켓몬을 바꾸면 이후 입력은 새로 선택한 개체에 적용된다.
- 중복 부화는 경험치를 채우지 않고 같은 색상 개체의 레벨을 즉시 1 올린다. 기존 경험치는 유지한다.

## 저장

- 입력마다 메모리 상태와 화면은 즉시 갱신한다.
- 디스크 쓰기는 최대 5초 단위로 모아 처리한다.
- 포켓몬 선택 변경은 즉시 저장한다.
- 창을 닫을 때 마지막 저장을 시도한다. 저장이 실패하면 오류를 표시하고 종료를 취소한다.
