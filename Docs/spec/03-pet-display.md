# 메인 창과 포켓몬 표시

## 창 구성

- 메인 창은 투명하고 테두리가 없으며 항상 다른 창 위에 표시된다.
- 작업 표시줄에는 앱 창을 표시하지 않는다. 창 크기는 현재 콘텐츠에 맞춰 자동 조절된다.
- 상단에는 포켓몬과 알을 표시한다. 하단에는 레벨, 경험치 바, 메뉴 탭과 펼침식 서랍을 표시한다.
- 첫 위치는 각 OS 작업 영역 오른쪽 아래에서 가로·세로 20px 안쪽이다.
- 실제 실행에서는 메인 창을 처음에 투명하게 유지한다. 선택한 포켓몬과 알 그림을 먼저 준비하며, 로드 실패 시에는 각각 대체 화면을 준비한다. 두 그림의 준비가 끝난 뒤 누적 성장에 따른 진화를 확인하고 필요한 연출까지 모두 마친 다음 최종 크기로 배치해 한 번에 표시한다. 준비 중 전역 입력 경험치는 보존하되, 알 그림을 기다리는 동안 레벨이 올라가도 진화 실행은 두 그림의 준비 완료까지 보류한다. 준비 중 닫으면 뒤늦게 창을 다시 표시하지 않는다. 서비스를 시작하지 않는 디자이너·테스트 미리보기는 즉시 표시한다.
- 버튼이나 알이 아닌 투명 배경을 좌클릭 드래그하면 창 전체가 이동한다.
- 우클릭 메뉴의 **종료**로 앱을 닫는다. Debug 빌드는 개발 메뉴도 추가한다.

## 포켓몬 표시

- 일반 또는 이로치 스프라이트를 표시한다. 이로치 선택 시 레벨 앞에 `★`를 붙인다.
- 애니메이션 프레임은 100ms 간격, 즉 10fps로 무한 반복한다.
- 프레임 전체 캔버스가 아닌 모든 프레임의 실제 불투명 몸체 영역 합집합을 크기 계산에 사용한다.
- 목표 몸체 높이는 `PokemonDisplaySize.TargetHeight`로 종마다 완만하게 달라진다. 고정 PokeAPI `pokemon.csv`의 높이 `h`(데시미터)를 내장한 `pokemon-sizes.json`에서 읽고, `84 + 12 × log2(h / 10)`을 2 DIP 단위로 반올림한 뒤 72~100 DIP로 제한한다. 데이터가 없으면 84 DIP를 사용한다.
- 파이리·리자드·리자몽의 목표 높이는 각각 **76·86·94 DIP**다. 크기 계산에는 일반·이로치가 같은 종 높이를 사용한다. 목표 높이를 몸체 픽셀 높이로 나눈 정확한 배율을 적용하며, 배율을 0.25 단위로 다시 반올림하지 않는다. 픽셀 확대에는 최근접 보간을 사용한다.
- 꼬리·날개가 매우 넓은 경우에만 발 중심 기준 좌우 공간이 212 DIP(220 DIP 표시 열에서 양쪽 여백 4 DIP 제외)에 들어오도록 비율을 유지하며 줄인다. 일반·이로치와 진화 전후에 같은 크기 계산을 사용한다.
- 각 프레임의 실제 불투명 픽셀 하단을 발 높이로 사용한다. 하단 10%(최대 6픽셀) 영역의 가로 중심을 구하고, 프레임들의 중앙값을 가로 기준으로 고정해 꼬리·불꽃·투명 여백에 몸체가 밀리거나 프레임마다 좌우로 흔들리지 않게 한다. 발이 없는 포켓몬은 보이는 몸체 하단을 기준으로 한다.
- 평소 본체와 진화 실루엣 모두 이 발 기준점을 그림자의 실제 타원 중심에 놓는다. 좌우 반전과 UI 확대 후에도 같은 기준선에 닿으며, 꼬리와 날개가 잘리지 않도록 발 중심 양옆의 공간을 확보한다.
- 스프라이트가 바뀌어 창 크기가 변해도 기존 발 위치와 가로 중심이 유지되도록 창 위치를 보정한다.
- 로드 실패 시 포켓몬 이름과 **이미지 없음** 문구를 표시한다. 도감에서 새 포켓몬을 선택하다 실패하면 기존 선택과 스프라이트를 유지한다.
- 진화 중에는 우클릭 메뉴의 스프라이트 다시 불러오기를 무시한다. 이전 종의 로드가 진화 완료 후 본체 이미지를 덮지 않도록 한다.

## 반응 애니메이션

- 전역 입력 1회마다 포켓몬이 약 0.22초 동안 눌렸다가 위로 늘어나며 원래 형태로 돌아온다.
- 같은 입력이 경험치 증가도 발생시킨다.
- 레벨업 시 레벨 글자를 약 1.5배로 키웠다가 0.35초 안에 원래 크기로 되돌린다.

## 공통 픽셀 UI

- Windows와 macOS 모두 같은 Avalonia 마크업, `Assets/PixelUI`의 PNG와 번들 Galmuri11/Galmuri9 폰트를 사용한다.
- 기본 레이아웃은 352 DIP 폭이다. `UiZoom`이 전체 UI의 배율을 적용하며, 스프라이트의 몸체 크기 보정과 UI 배율은 별개다.
- 참고 화면 `design/reference-ui-target.png`를 기준으로 투명한 상단, 픽셀 그림자, EXP 표시판, 빨간 탭, 크림색 패널을 구성한다.
- PNG는 2px 격자로 제작됐다. 원본의 2px을 논리 1px로 사용하고 최근접 보간으로 표시한다.
  `PixelSurface`는 패널 모서리와 테두리 두께를 보존해 내용 높이에 맞춰 그린다.
- 펫 이름은 레벨 영역을 제외한 한 줄 폭에 표시한다. 긴 이름은 말줄임표로 줄이고 전체 이름은 툴팁으로 제공한다. 포켓몬과 색상 선택이 바뀌면 표시 이름과 툴팁을 함께 갱신한다.
- 포켓몬 이름·레벨과 경험치 게이지를 펫 아래에, 남은 시간 또는 부화 안내판을 알 아래에 표시한다. 대기 중에는 16 DIP 글자로 `mm:ss` 시간만 표시하고, 준비되면 11 DIP 글자의 **클릭하여 부화**를 한 줄로 표시한다. 알 등급은 알이나 안내판에 마우스를 올렸을 때 툴팁으로 확인한다. 부화 결과는 이름·이로치 여부를 표시하며 긴 문구는 줄바꿈한다.
- 상단은 본체용 220 DIP와 알용 132 DIP 열로 나눈다. 본체와 경험치 영역을 왼쪽 두 행에 배치하고 알·안내판은 오른쪽에서 두 행을 함께 사용한다. 안내판과 EXP 표시판의 하단을 같은 기준선에 맞추므로 알 문구가 두 줄이 되거나 본체 높이가 달라져도 별도 위치 오프셋 없이 정렬을 유지한다.
- 포켓몬 방향 전환용 `PetFacing`은 몸체만 감싼다. 레벨·이름·도감·알 글자를 뒤집지 않고 바운스와 독립적으로 적용한다.
- 몸체 확대용 `StageZoom`의 바로 아래에는 변환을 공유하지 않는 `Border`를 두고, 그 안의 `PetFacing`에 좌우 반전을 적용한다. `LayoutTransformControl`이 자식의 `RenderTransform`을 관리하므로 이 계층을 분리해 확대·레이아웃 재계산이 반전을 덮어쓰지 않게 한다. 전체 UI 확대, 몸체 크기 보정, 좌우 반전과 바운스는 서로 독립적으로 유지한다.
- 진화 가능한 경우 펫 위에 알림을 표시하고 실제 출발 모습과 세대 팝업의 해당 선택 항목을 강조한다. 이전 모습을 선택 중이면 안내를 눌러 출발 모습의 도감을 연다. 현재 출발 모습을 선택하면 진화하며, 분기는 미수집 후보 중 무작위로 정해 사용자에게 목적지 선택창을 띄우지 않는다.
- 진화는 약 3.933초의 PokéRogue식 연출을 사용한다. 본체를 450ms 동안 흰 실루엣으로 덮고 350ms 유지한 뒤, 원본·목표 실루엣의 크기가 1배와 0.25배 사이를 점점 빠르게 왕복한다. 마지막 750ms에 목표의 실제 색상을 공개하며 흰색 덮개는 그 안에서 500ms 동안 사라진다. 시작에는 위로 올라가는 입자 12개, 공개 시에는 안쪽으로 모이는 입자 20개를 표시한다. 로딩·저장 시간은 별도다.
- 진화 효과는 현재 색상의 원본·목표 프레임 복사본을 100ms 간격으로 재생한다. 두 모습의 발을 그림자에 맞추고 각 종의 표시 크기와 현재 좌우 반전을 유지한다. 새 본체는 색상 공개가 끝날 때 교체하고, 실패·취소·창 닫기에는 임시 이미지를 해제한다. 완료 저장이 성공하기 전에는 목표의 실제 색상을 공개하지 않는다. 진화 중 입력 경험치는 계속 모으되 본체 바운스를 겹치지 않는다.
- 진화 연출 중 보유 포켓몬을 선택하면 현재 연출을 취소·정리한 뒤 새 선택을 적용한다. 완료 저장 전에는 예약한 진화 대상을 유지하고 새 보유를 지급하지 않으며, 저장 후에는 이미 얻은 모습과 성장을 유지한다. 취소된 연출의 늦은 완료가 새 선택을 덮지 않는다. 자세한 순서와 복구 규칙은 [11-evolution.md](11-evolution.md)를 따른다.
- 일반 버튼, 메뉴 탭, 세대 선택 항목, 도감 셀과 스타팅 선택 버튼은 포인터를 올리면 시각 레이어만 2 DIP 위로 이동한다. 120ms `CubicEaseOut` 전환을 사용하고 누르는 동안과 포인터가 벗어난 뒤에는 원래 위치로 돌아온다. 컨트롤의 배치·클릭 영역은 고정해 이웃 요소가 밀리거나 포인터 경계에서 반응이 반복되지 않게 한다.
- 포인터 hover 자체는 내부 테두리나 PNG 에셋 색상을 바꾸지 않는다. 비활성 버튼과 미보유 도감 셀은 떠오르지 않는다. 선택 상태, 진화 가능 표시와 템플릿 내부의 키보드 포커스 표시는 유지하며 별도 포커스 오버레이가 포인터를 가로채지 않게 한다. 미보유 셀은 밝은 청록색 일반 칸에 청남색 실루엣을 표시한다. 어두운 칸은 그림이 누락된 물음표 셀에 사용한다.
- 일반 버튼은 좌우 화살표 받침이 없는 크림색 `egg_timer_plate`를 4 DIP 모서리로 늘려 쓴다. 체크박스는 행 전체의 클릭 영역과 글자 위치를 유지하고 체크 칸의 시각 레이어만 같은 방식으로 떠오른다. 키보드 포커스 윤곽선은 체크 칸 안에만 표시한다.

## 도감·박스·설정 서랍

- 메뉴는 **도감**, **박스**, **설정**의 3개 탭이다. 각각 도감책·상자·톱니바퀴 아이콘을 표시하며 선택된 탭은 노란색, 나머지는 빨간색이다. 탭 뒤에 별도 빨간 받침 이미지를 두지 않는다. 42 DIP 높이의 탭 영역에서 세 버튼은 각각 116 DIP이며 앞의 두 경계를 각각 2 DIP 겹쳐 탭 행 폭을 344 DIP로 맞춘다. 352 DIP 서랍의 양옆에서 4 DIP씩 안으로 배치해 탭의 색상 면과 서랍 안쪽 크림색 면의 경계를 맞춘다. 탭의 어두운 외곽선은 서랍 외곽보다 4 DIP 안에 놓인다. 탭 행과 서랍은 2 DIP 겹쳐 연결한다.
- 같은 탭을 다시 누르면 접히고, 다른 탭을 누르면 해당 내용으로 전환한다.
- 도감과 박스에는 세대·필터, 6열 목록과 상세 영역을 표시한다. 박스에서는 **보유만**을 켠 채 비활성화하며, 도감으로 돌아오면 기존 보유 필터를 복원한다. 설정에는 좌우 뒤집기, 로그인 시 자동 실행, 화면 크기와 종료 버튼을 표시한다.
- 세대 선택은 117×31 DIP의 화살표 선택기와 팝업으로 제공한다. 39 DIP 높이의 도구막대 한 행에 세대·보유 필터·별 모양 이로치 필터·보유 수를 둔다. 선택 동작은 [도감 명세](05-pokedex.md)를 따른다.
- 서랍 콘텐츠는 `DrawerScroll`로 감싼다. 코드에서 작업 영역과 현재 UI 배율에 맞춰 최대 높이를 제한할 수 있으며, 넘치는 내용은 스크롤한다.
- 펼침/접힘은 250ms 동안 진행한다. 패널 높이가 바뀔 때 하단 위치를 유지하고, 접으면 펼치기 전 위치를 복원한다.
- 닫기 애니메이션이 끝나도 실제 창의 마지막 크기 변경과 위치 보정이 완료되기 전에는 복귀 기준점을 유지한다. 느린 환경에서 창 크기 알림이 늦게 도착하거나 위쪽 화면 경계에 닿았어도 원래 자리로 돌아간다.
- 열린 서랍의 오류·안내 문구나 상세 내용이 변하면 새 콘텐츠 높이로 애니메이션을 이어간다. 최대 높이를 넘으면 내부 스크롤로 모든 내용을 볼 수 있으며, 닫는 중 콘텐츠가 변해도 다시 열리지 않는다. 이때도 펼치기 전 위치를 유지한다.
- 실제 화면 바깥으로 나가는 경우 작업 영역 안으로 보정한다. 위치 보정과 UI 배율 처리는 메인 창 컨트롤러에서 수행한다.
- 창을 다른 모니터로 옮기거나 모니터 배율·작업 영역이 바뀌면 새 화면에 맞춰 실제 UI 배율과 서랍 스크롤 높이를 다시 계산한다. 저장한 배율은 유지한다. 위치·DPI·화면 변경 알림을 한 번으로 모으고 실제 화면 조건이 바뀐 경우에만 처리해 앱 자신의 위치 보정이 반복 호출을 만들지 않게 한다. 열린 서랍은 새 영역에서 다시 측정하고, 닫기 동작은 이동한 화면의 위치를 기준으로 돌아온다.
