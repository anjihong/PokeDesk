# 메인 창과 포켓몬 표시

## 창 구성

- 메인 창은 투명하고 테두리가 없으며 항상 다른 창 위에 표시된다.
- 작업 표시줄에는 앱 창을 표시하지 않는다. 창 크기는 현재 콘텐츠에 맞춰 자동 조절된다.
- 상단에는 포켓몬과 알을 표시한다. 하단에는 레벨, 경험치 바, 메뉴 탭과 펼침식 서랍을 표시한다.
- 첫 위치는 각 OS 작업 영역 오른쪽 아래에서 가로·세로 20px 안쪽이다.
- 실제 실행에서는 메인 창을 처음에 투명하게 유지한다. 선택한 포켓몬과 알 그림을 먼저 준비하며, 로드 실패 시에는 각각 대체 화면을 준비한다. 두 그림의 준비가 끝난 뒤 누적 성장에 따른 진화를 확인하고 필요한 연출까지 모두 마친 다음 최종 크기로 배치해 한 번에 표시한다. 준비 중 전역 입력 경험치는 보존하되, 알 그림을 기다리는 동안 레벨이 올라가도 진화 실행은 두 그림의 준비 완료까지 보류한다. 준비 중 닫으면 뒤늦게 창을 다시 표시하지 않는다. 서비스를 시작하지 않는 디자이너·테스트 미리보기는 즉시 표시한다.
- 버튼이나 알이 아닌 투명 배경을 좌클릭 드래그하면 창 전체가 이동한다.
- 우클릭 메뉴의 **종료**로 앱을 닫는다. Debug 빌드는 개발 메뉴도 추가한다.

## 포켓몬 표시

- 일반 또는 이로치 스프라이트를 표시한다. 이로치 선택 시 레벨 앞에 `★`를 붙인다.
- 애니메이션 프레임은 100ms 간격, 즉 10fps로 무한 반복한다.
- 프레임 전체 캔버스가 아닌 모든 프레임의 실제 불투명 몸체 영역 합집합을 크기 계산에 사용한다.
- 목표 몸체 높이는 `PokemonDisplaySize.TargetHeight`로 종마다 완만하게 달라진다. 고정 PokeAPI `pokemon.csv`의 높이 `h`(데시미터)를 내장한 `pokemon-sizes.json`에서 읽고, `104 + 12 × log2(h / 10)`을 2 DIP 단위로 반올림한 뒤 92~120 DIP로 제한한다. 데이터가 없으면 104 DIP를 사용한다.
- 파이리·리자드·리자몽의 목표 높이는 각각 **96·106·114 DIP**다. 크기 계산에는 일반·이로치가 같은 종 높이를 사용한다. 목표 높이를 몸체 픽셀 높이로 나눈 정확한 배율을 적용하며, 배율을 0.25 단위로 다시 반올림하지 않는다. 픽셀 확대에는 최근접 보간을 사용한다.
- 꼬리·날개가 매우 넓은 경우에만 발 중심 기준 좌우 공간이 212 DIP(236 DIP 표시 열에서 양쪽 여백 12 DIP 제외)에 들어오도록 비율을 유지하며 줄인다. 일반·이로치와 진화 전후에 같은 크기 계산을 사용한다.
- 각 프레임의 실제 불투명 픽셀 하단을 발 높이로 사용한다. 하단 10%(최대 6픽셀) 영역의 가로 중심을 구하고, 프레임들의 중앙값을 가로 기준으로 고정해 꼬리·불꽃·투명 여백에 몸체가 밀리거나 프레임마다 좌우로 흔들리지 않게 한다. 발이 없는 포켓몬은 보이는 몸체 하단을 기준으로 한다.
- 평소 본체와 진화 실루엣 모두 이 발 기준점을 그림자의 실제 타원 중심에 놓는다. 좌우 반전과 UI 확대 후에도 같은 기준선에 닿으며, 꼬리와 날개가 잘리지 않도록 발 중심 양옆의 공간을 확보한다.
- 스프라이트가 바뀌어 창 크기가 변해도 기존 발 위치와 가로 중심이 유지되도록 창 위치를 보정한다.
- 로드 실패 시 포켓몬 이름과 **이미지 없음** 문구를 표시한다. 도감에서 새 포켓몬을 선택하다 실패하면 기존 선택과 스프라이트를 유지한다.
- 진화 중에는 우클릭 메뉴의 스프라이트 다시 불러오기를 무시한다. 이전 종의 로드가 진화 완료 후 본체 이미지를 덮지 않도록 한다.

## 반응 애니메이션

- 전역 입력 1회마다 포켓몬이 약 0.22초 동안 눌렸다가 위로 늘어나며 원래 형태로 돌아온다.
- 같은 입력이 경험치 증가도 발생시킨다.
- 레벨업 시 레벨 글자를 약 1.5배로 키웠다가 0.35초 안에 원래 크기로 되돌린다.

## 공통 픽셀 UI

- Windows와 macOS 모두 같은 Avalonia 마크업, `Assets/PixelUI`의 PNG와 번들 Galmuri11/Galmuri9 폰트를 사용한다.
- 기본 레이아웃은 352 DIP 폭이다. `UiZoom`이 전체 UI의 배율을 적용하며, 스프라이트의 몸체 크기 보정과 UI 배율은 별개다.
- 참고 화면 `design/reference-ui-target.png`를 기준으로 투명한 상단, 픽셀 그림자, EXP 표시판, 빨간 탭, 크림색 패널을 구성한다.
- PNG는 2px 격자로 제작됐다. 원본의 2px을 논리 1px로 사용하고 최근접 보간으로 표시한다.
  `PixelSurface`는 패널 모서리와 테두리 두께를 보존해 내용 높이에 맞춰 그린다.
- 포켓몬 이름·레벨과 경험치 게이지를 펫 아래에, 등급·남은 시간 또는 부화 안내판을 알 아래에 표시한다.
- 본체와 경험치 영역을 왼쪽 두 행에 배치하고 알·안내판은 오른쪽에서 두 행을 함께 사용한다. 안내판과 EXP 표시판의 하단을 같은 기준선에 맞추므로 알 문구가 두 줄이 되거나 본체 높이가 달라져도 별도 위치 오프셋 없이 정렬을 유지한다.
- 포켓몬 방향 전환용 `PetFacing`은 몸체만 감싼다. 레벨·이름·도감·알 글자를 뒤집지 않고 바운스와 독립적으로 적용한다.
- 몸체 확대용 `StageZoom`의 바로 아래에는 변환을 공유하지 않는 `Border`를 두고, 그 안의 `PetFacing`에 좌우 반전을 적용한다. `LayoutTransformControl`이 자식의 `RenderTransform`을 관리하므로 이 계층을 분리해 확대·레이아웃 재계산이 반전을 덮어쓰지 않게 한다. 전체 UI 확대, 몸체 크기 보정, 좌우 반전과 바운스는 서로 독립적으로 유지한다.
- 진화 가능한 경우 펫 위에 알림을 표시하고 실제 출발 모습과 해당 세대 탭을 강조한다. 이전 모습을 선택 중이면 안내를 눌러 출발 모습의 도감을 연다. 현재 출발 모습을 선택하면 진화하며, 분기는 미수집 후보 중 무작위로 정해 사용자에게 목적지 선택창을 띄우지 않는다.
- 진화 시 약 2.8초 동안 본체에 빛이 모이고 흰 실루엣이 다음 형태로 점차 겹쳐 바뀐 뒤 새 색상이 드러난다. 연출은 본체 확대·바운스와 별도의 발 하단 기준 레이어에서 표시하며 좌우 반전은 현재 설정을 따른다. 진화 중에는 입력 경험치를 계속 모으되 본체 바운스를 겹치지 않는다.
- 진화 효과는 현재 색상의 원본·목표 프레임 복사본을 사용한다. 새 본체는 색상 공개가 끝날 때 교체하고, 실패·취소·창 닫기에는 임시 이미지를 해제한다. 저장이 성공하기 전에는 목표의 실제 색상을 공개하지 않는다. 자세한 순서와 복구 규칙은 [11-evolution.md](11-evolution.md)를 따른다.
- 일반 버튼, 메뉴 탭, 세대 탭, 도감 셀과 스타팅 선택 버튼은 포인터를 올리면 시각 레이어만 2 DIP 위로 이동한다. 120ms `CubicEaseOut` 전환을 사용하고 누르는 동안과 포인터가 벗어난 뒤에는 원래 위치로 돌아온다. 컨트롤의 배치·클릭 영역은 고정해 이웃 요소가 밀리거나 포인터 경계에서 반응이 반복되지 않게 한다.
- 포인터 hover 자체는 내부 테두리나 PNG 에셋 색상을 바꾸지 않는다. 비활성 버튼과 미보유 도감 셀은 떠오르지 않는다. 선택 상태, 진화 가능 표시와 템플릿 내부의 키보드 포커스 표시는 유지하며 별도 포커스 오버레이가 포인터를 가로채지 않게 한다. 미보유 셀은 색을 흐리게 처리하지 않고 실루엣과 어두운 칸으로 구분한다.
- 일반 버튼은 좌우 화살표 받침이 없는 크림색 `egg_timer_plate`를 4 DIP 모서리로 늘려 쓴다. 체크박스는 행 전체의 클릭 영역과 글자 위치를 유지하고 체크 칸의 시각 레이어만 같은 방식으로 떠오른다. 키보드 포커스 윤곽선은 체크 칸 안에만 표시한다.

## 도감·설정 서랍

- 메뉴는 **도감**, **설정** 두 탭이다. 비활성 메뉴 2·3 자리표시는 표시하지 않는다.
- 같은 탭을 다시 누르면 접히고, 다른 탭을 누르면 해당 내용으로 전환한다.
- 도감에는 세대·필터, 6열 목록과 상세 영역을 표시한다. 설정에는 좌우 뒤집기, 로그인 시 자동 실행, 화면 크기와 종료 버튼을 표시한다.
- 서랍 콘텐츠는 `DrawerScroll`로 감싼다. 코드에서 작업 영역과 현재 UI 배율에 맞춰 최대 높이를 제한할 수 있으며, 넘치는 내용은 스크롤한다.
- 펼침/접힘은 250ms 동안 진행한다. 패널 높이가 바뀔 때 하단 위치를 유지하고, 접으면 펼치기 전 위치를 복원한다.
- 닫기 애니메이션이 끝나도 실제 창의 마지막 크기 변경과 위치 보정이 완료되기 전에는 복귀 기준점을 유지한다. 느린 환경에서 창 크기 알림이 늦게 도착하거나 위쪽 화면 경계에 닿았어도 원래 자리로 돌아간다.
- 열린 서랍의 오류·안내 문구나 상세 내용이 변하면 새 콘텐츠 높이로 애니메이션을 이어간다. 최대 높이를 넘으면 내부 스크롤로 모든 내용을 볼 수 있으며, 닫는 중 콘텐츠가 변해도 다시 열리지 않는다. 이때도 펼치기 전 위치를 유지한다.
- 실제 화면 바깥으로 나가는 경우 작업 영역 안으로 보정한다. 위치 보정과 UI 배율 처리는 메인 창 컨트롤러에서 수행한다.
