# 메인 창과 포켓몬 표시

## 창 구성

- 메인 창은 투명하고 테두리가 없으며 항상 다른 창 위에 표시된다.
- 작업 표시줄에는 앱 창을 표시하지 않는다. 창 크기는 현재 콘텐츠에 맞춰 자동 조절된다.
- 상단에는 포켓몬과 알을 표시한다. 하단에는 레벨, 경험치 바, 메뉴 탭과 펼침식 서랍을 표시한다.
- 첫 위치는 각 OS 작업 영역 오른쪽 아래에서 가로·세로 20px 안쪽이다.
- 버튼이나 알이 아닌 투명 배경을 좌클릭 드래그하면 창 전체가 이동한다.
- 우클릭 메뉴의 **종료**로 앱을 닫는다. Debug 빌드는 개발 메뉴도 추가한다.

## 포켓몬 표시

- 일반 또는 이로치 스프라이트를 표시한다. 이로치 선택 시 레벨 앞에 `★`를 붙인다.
- 애니메이션 프레임은 100ms 간격, 즉 10fps로 무한 반복한다.
- 프레임 전체 캔버스가 아닌 모든 프레임의 실제 불투명 몸체 영역 합집합을 크기 계산에 사용한다.
- 기본 목표는 몸체 높이 110px이다. 몸체 너비가 170px을 넘지 않도록 더 작은 배율을 선택한다.
- 배율은 최소 1배이며 0.25 단위로 반올림한다. 픽셀 확대에는 최근접 보간을 사용한다.
- 스프라이트가 바뀌어 창 크기가 변해도 기존 발 위치와 가로 중심이 유지되도록 창 위치를 보정한다.
- 로드 실패 시 포켓몬 이름과 **이미지 없음** 문구를 표시한다. 도감에서 새 포켓몬을 선택하다 실패하면 기존 선택과 스프라이트를 유지한다.
- 진화 중에는 우클릭 메뉴의 스프라이트 다시 불러오기를 무시한다. 이전 종의 로드가 진화 완료 후 본체 이미지를 덮지 않도록 한다.

## 반응 애니메이션

- 전역 입력 1회마다 포켓몬이 약 0.22초 동안 눌렸다가 위로 늘어나며 원래 형태로 돌아온다.
- 같은 입력이 경험치 증가도 발생시킨다.
- 레벨업 시 레벨 글자를 약 1.5배로 키웠다가 0.35초 안에 원래 크기로 되돌린다.

## 공통 픽셀 UI

- Windows와 macOS 모두 같은 Avalonia 마크업, `Assets/PixelUI`의 PNG와 번들 Galmuri11/Galmuri9 폰트를 사용한다.
- 기본 레이아웃은 352 DIP 폭이다. `UiZoom`이 전체 UI의 배율을 적용하며, 스프라이트의 몸체 크기 보정과 UI 배율은 별개다.
- 참고 화면 `design/reference-ui-target.png`를 기준으로 투명한 상단, 픽셀 그림자, EXP 표시판, 빨간 탭, 크림색 패널을 구성한다.
- PNG는 2px 격자로 제작됐다. 원본의 2px을 논리 1px로 사용하고 최근접 보간으로 표시한다.
  `PixelSurface`는 패널 모서리와 테두리 두께를 보존해 내용 높이에 맞춰 그린다.
- 포켓몬 이름·레벨과 경험치 게이지를 펫 아래에, 등급·남은 시간 또는 부화 안내판을 알 아래에 표시한다.
- 본체와 경험치 영역을 왼쪽 두 행에 배치하고 알·안내판은 오른쪽에서 두 행을 함께 사용한다. 안내판과 EXP 표시판의 하단을 같은 기준선에 맞추므로 알 문구가 두 줄이 되거나 본체 높이가 달라져도 별도 위치 오프셋 없이 정렬을 유지한다.
- 포켓몬 방향 전환용 `PetFacing`은 몸체만 감싼다. 레벨·이름·도감·알 글자를 뒤집지 않고 바운스와 독립적으로 적용한다.
- 몸체 확대용 `StageZoom`의 바로 아래에는 변환을 공유하지 않는 `Border`를 두고, 그 안의 `PetFacing`에 좌우 반전을 적용한다. `LayoutTransformControl`이 자식의 `RenderTransform`을 관리하므로 이 계층을 분리해 확대·레이아웃 재계산이 반전을 덮어쓰지 않게 한다. 전체 UI 확대, 몸체 크기 보정, 좌우 반전과 바운스는 서로 독립적으로 유지한다.
- 진화 가능한 경우 펫 위의 진화 알림과 분기 선택 영역을 사용한다. 표시 조건과 선택 처리는 진화 규칙을 따른다.
- 버튼·탭·체크박스는 hover/선택 상태와 키보드 포커스 표시를 제공한다. 미보유 셀은 색을 흐리게 처리하지 않고 실루엣과 어두운 칸으로 구분한다.
- 일반 버튼은 좌우 화살표 받침이 없는 크림색 `egg_timer_plate`를 4 DIP 모서리로 늘려 쓴다. 체크박스는 행 전체의 클릭 영역을 유지하되 hover·키보드 포커스 윤곽선은 체크 칸 안에만 표시해 패널 위에 불필요한 긴 테두리가 생기지 않게 한다.

## 도감·설정 서랍

- 메뉴는 **도감**, **설정** 두 탭이다. 비활성 메뉴 2·3 자리표시는 표시하지 않는다.
- 같은 탭을 다시 누르면 접히고, 다른 탭을 누르면 해당 내용으로 전환한다.
- 도감에는 세대·필터, 6열 목록과 상세 영역을 표시한다. 설정에는 좌우 뒤집기, 로그인 시 자동 실행, 화면 크기와 종료 버튼을 표시한다.
- 서랍 콘텐츠는 `DrawerScroll`로 감싼다. 코드에서 작업 영역과 현재 UI 배율에 맞춰 최대 높이를 제한할 수 있으며, 넘치는 내용은 스크롤한다.
- 펼침/접힘은 250ms 동안 진행한다. 패널 높이가 바뀔 때 하단 위치를 유지하고, 접으면 펼치기 전 위치를 복원한다.
- 열린 서랍의 오류·안내 문구나 상세 내용이 변하면 새 콘텐츠 높이로 애니메이션을 이어간다. 최대 높이를 넘으면 내부 스크롤로 모든 내용을 볼 수 있으며, 닫는 중 콘텐츠가 변해도 다시 열리지 않는다. 이때도 펼치기 전 위치를 유지한다.
- 실제 화면 바깥으로 나가는 경우 작업 영역 안으로 보정한다. 위치 보정과 UI 배율 처리는 메인 창 컨트롤러에서 수행한다.
