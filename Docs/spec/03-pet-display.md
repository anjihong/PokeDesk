# 메인 창과 포켓몬 표시

- 메인 창에는 포켓몬 스프라이트, 레벨과 경험치 바, 알과 말풍선, 메뉴 탭과 도감 서랍이 배치된다.
- 처음 표시되는 위치는 Windows 작업 영역의 오른쪽 아래에서 가로·세로 각각 20px 안쪽이다. 빈 배경을 좌클릭 드래그해 창을 옮길 수 있다.
- 포켓몬 애니메이션은 프레임을 100ms 간격으로 순환한다. 프레임의 실제 픽셀 영역 합집합을 기준으로 몸체 높이 110px, 최대 너비 170px을 목표로 확대하며 배율은 0.25 단위로 반올림한다.
- 스프라이트 변경으로 창 크기가 달라져도 기존 발 위치를 유지하도록 창 위치를 보정한다. 도감 서랍은 250ms 애니메이션으로 열고 닫으며 작업 영역 아래로 넘치면 창을 위로 이동시킨다.
- 전역 입력 1회마다 포켓몬이 약 0.22초간 눌렸다가 튀어 오르는 애니메이션을 재생한다.
