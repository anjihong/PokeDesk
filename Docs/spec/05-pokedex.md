# 도감과 포켓몬 선택

## 세대 구분

도감은 전국도감 `#1~#1025`를 다음 범위로 나눈다. 전체 세대를 한 번에 보는 탭은 없다.

| 세대 | 도감 번호 | 종 수 |
| ---: | --- | ---: |
| 1 | `#1~#151` | 151 |
| 2 | `#152~#251` | 100 |
| 3 | `#252~#386` | 135 |
| 4 | `#387~#493` | 107 |
| 5 | `#494~#649` | 156 |
| 6 | `#650~#721` | 72 |
| 7 | `#722~#809` | 88 |
| 8 | `#810~#905` | 96 |
| 9 | `#906~#1025` | 120 |

메인 창을 열면 현재 선택 포켓몬이 속한 세대 탭을 선택한다. 세대 탭을 바꾸면 목록을 다시 만들고 스크롤을 맨 위로 이동한다.

## 셀 표시

- 보유 종은 실제 아이콘으로 표시하며 선택할 수 있다.
- 일반 보유 툴팁은 `#번호 이름 · Lv.n` 형식이다.
- 이로치 보유 툴팁은 `#번호 이름 ★ 이로치 · Lv.n` 형식이다.
- 미보유 종은 아이콘의 알파를 유지한 어두운 실루엣으로 표시한다.
- 미보유 툴팁은 이름 대신 `???`를 표시하며 선택할 수 없다.
- 아틀라스에 해당 아이콘 프레임이 없으면 그 셀은 목록에 만들지 않는다.

## 필터와 보유 수

- **보유만 보기**를 켜면 현재 세대에서 보유한 셀만 남긴다.
- **이로치 도감**을 켜면 아이콘, 보유 목록, 레벨, 실루엣과 보유 수 기준을 모두 이로치로 바꾼다.
- 이로치 도감 전환만으로 메인 화면의 현재 포켓몬은 바뀌지 않는다.
- 보유 수는 현재 보고 있는 색상 기준 `보유 수/1025`로 표시한다. 세대별 수가 아니라 전체 수다.
- Debug의 전체 해금을 켜면 보유 수를 `1025/1025`로 표시하지만 실제 보유 목록은 바꾸지 않는다.

## 포켓몬 선택

1. 보유 셀을 누르면 해당 색상의 본체 스프라이트를 비동기로 로드한다.
2. 로드가 성공한 뒤 `SelectedDex`, `SelectedShiny`, 레벨과 경험치 표시를 바꾼다.
3. 선택 상태를 즉시 저장하고 노란 테두리를 새 셀로 옮긴다.
4. 로드가 실패하면 오류 메시지를 표시하고 기존 선택을 유지한다.

빠르게 여러 셀을 누르면 이전 요청 결과를 버리고 마지막 요청만 반영한다. 부화로 보유 상태가 바뀌면 현재 보고 있는 같은 색상·세대의 셀과 보유 수를 갱신한다.

이로치 도감 상세 규칙은 [10-shiny.md](10-shiny.md)를 참고한다.
