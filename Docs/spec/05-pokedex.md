# 도감·박스와 포켓몬 선택

## 픽셀 UI 구성

- 공통 352 DIP 폭의 크림색 프레임 안에 세대 선택, 보유/이로치 필터, 청록색 목록과 상세 패널을 배치한다.
- 39 DIP 높이의 도구막대 한 행에 117×31 DIP 세대 선택기, **보유만** 체크박스, 별 모양 **이로치만** 체크박스와 보유 수를 배치한다. 별 체크박스에는 체크 칸·글자·내부 여백이 들어가는 40 DIP 폭을 확보하고, 양옆의 6 DIP 간격으로 보유 필터·보유 수와 분리한다. 별 글자가 인접 컨트롤이나 자신의 여백에 잘리지 않게 하며 툴팁과 접근성 이름으로 이로치 필터임을 알린다. 세대 선택기의 가운데 버튼은 `전체`와 1~9세대를 고르는 팝업을 연다.
- 보유 수는 기본 13 DIP 글자로 표시한다. 최대 보유 수 `보유 2072/2072`가 할당된 폭을 넘을 때만 비율을 줄여 표시하고 숫자를 자르거나 별 필터 영역을 침범하지 않는다.
- 기본 목록은 6열이다. 각 칸은 52×52 DIP이며 오른쪽·아래쪽에 1 DIP 간격을 둔다. 기본 스크롤 높이는 214 DIP로, 네 행 212 DIP와 첫 행의 호버 여백 2 DIP를 함께 수용한다. 호버 시 위로 이동하는 시각 레이어와 클릭 영역은 분리한다.
- 목록 패널은 여백을 포함한 6칸에 해당하는 318 DIP 폭을 유지한다. 보유 필터로 한두 칸만 남아도 첫 번째 열부터 표시하며 목록 전체가 가운데로 이동하지 않는다.
- 일반 칸과 미보유 실루엣 칸에는 밝은 청록색 `slot_normal`, 선택된 칸에는 `slot_selected`, 그림이 누락된 물음표 칸에는 어두운 `slot_unknown`을 사용한다. 호버 시에는 그림을 교체하거나 테두리를 추가하지 않고 칸의 UI만 120ms 동안 2 DIP 올린다. 클릭 영역과 목록 배치는 고정한다. 선택된 칸은 노란 테두리, 키보드 포커스는 밝은 안쪽 테두리를 표시한다. 공통 버튼 동작은 [메인 창 명세](03-pet-display.md)를 따른다.
- 목록 로딩/실패 상태와 **다시 시도**는 목록 위의 별도 영역에서 제공한다.
- 하단 상세 패널은 선택한 포켓몬의 초상, 이름, 전국도감 번호, 한글 타입과 설명을 표시한다. 레벨·현재 경험치·필요 경험치는 상세 헤더에 마우스를 올렸을 때 툴팁으로 표시하며 설명 본문에는 성장 수치 줄을 넣지 않는다.
- 상세 헤더의 이름과 타입은 같은 행에서 시작하고, 긴 이름·복수 타입은 번호 배지를 침범하지 않도록 다음 줄로 흐른다. 번호는 오른쪽 위에 고정하고 구분선과 설명은 헤더 전체 아래에 배치해 글자·배지와 겹치지 않게 한다. 설명은 두 줄을 넘으면 말줄임표로 표시하고, 설명 위에 마우스를 올리면 원문 전체를 보여 준다. 일반 이름에서는 참고 이미지의 79 DIP 상세 패널 높이를 유지한다.
- 타입 배지는 최소 48 DIP 폭을 유지하고 긴 복수 타입에 맞춰 최대 166 DIP까지 늘어난다. `물`·`불꽃`처럼 짧은 타입도 글자의 실제 폭을 기준으로 배지의 가로·세로 가운데에 배치한다.
- 폰트는 Galmuri11, 보조 텍스트는 Galmuri9다. 상세 설명은 13 DIP 굵은 글자로 표시하고 사용 가능한 폭에 맞춰 줄바꿈한다. 레이아웃·상태별 PNG·폰트는 Windows와 macOS에서 함께 사용한다.

## 세대 구분

도감은 전국도감 `#1~#1025` 기본종과 지역 모습 11개를 합친 **1,036개 모습**을 표시한다. 각 세대의 기본종을 전국도감 번호순으로 둔 뒤 그 세대의 지역 모습을 추가하며, **전체** 선택은 이 세대 목록을 1~9 순으로 합친다. 기본 혼합 목록에는 일반 1,036칸에 실제 보유한 이로치 칸이 추가된다. 같은 모습을 두 색상으로 보유하면 일반 칸 바로 다음에 이로치 칸을 둔다.

| 세대 | 기본종 도감 번호 | 지역 모습 포함 칸 수 |
| ---: | --- | ---: |
| 1 | `#1~#151` | 151 |
| 2 | `#152~#251` | 100 |
| 3 | `#252~#386` | 135 |
| 4 | `#387~#493` | 107 |
| 5 | `#494~#649` | 156 |
| 6 | `#650~#721` | 72 |
| 7 | `#722~#809` | 88 |
| 8 | `#810~#905` | 106 (기본 96 + 지역 10) |
| 9 | `#906~#1025` | 121 (기본 120 + 지역 1) |

메인 창을 열면 현재 선택 포켓몬이 속한 세대를 선택한다. 왼쪽·오른쪽 화살표는 `전체(0) → 1세대 → … → 9세대` 순서로 한 칸씩 이동한다. 양 끝을 넘겨 순환하지 않으며 전체에서는 이전, 9세대에서는 다음 버튼을 비활성화한다. 가운데 세대 이름을 누르면 10개 항목의 팝업을 열어 바로 선택할 수 있고, 선택하면 팝업을 닫는다. 세대를 바꾸면 목록을 다시 만들고 스크롤을 맨 위로 이동한다. 전체 선택은 9개 세대의 아이콘을 함께 로드한다.

## 셀 표시

- 보유 종은 실제 아이콘으로 표시하며 선택할 수 있다.
- 일반 보유 툴팁은 `#번호 이름 · Lv.n` 형식이다. 번호는 지역 모습 내부 ID가 아닌 전국도감 번호이며, 가라르 나옹은 `#52 가라르 나옹`으로 표시한다. 레벨은 `Settings.For`로 연결된 육성 회차에서 읽는다.
- 이로치 보유 툴팁은 `#번호 이름 ★ 이로치 · Lv.n` 형식이다. 이로치 칸의 오른쪽 위에는 작은 **★ 배지**를 표시하여 일반 칸과 구별한다.
- 미보유 종은 아이콘의 알파를 유지한 청남색(`#123D53`) 실루엣으로 표시한다. 보유 칸과 같은 밝은 청록색 배경을 유지하며 선택할 수 없다.
- 미보유 툴팁은 이름 대신 `???`를 표시하며 선택할 수 없다.
- 아틀라스가 아직 로드되지 않았거나 해당 프레임이 없으면 `?` 셀을 유지한다. 그림 누락 때문에 도감 번호나 셀 수가 줄어들지 않는다.
- 보유 종은 그림이 없어도 선택할 수 있다. 미보유 종은 그림 유무와 관계없이 선택할 수 없다.
- 진화 가능한 현재 출발 모습은 별도 강조 상태와 툴팁의 `· 진화 가능`을 표시한다. 진화할 수 있는 모습이 속한 세대와 전체 항목은 세대 팝업에서도 강조한다.

## 로딩, 오류와 재시도

- 로드를 시작하면 캐시된 그림과 `?` 셀을 즉시 표시하고 로딩 안내를 보여 준다.
- 일부 세대의 다운로드가 실패해도 성공한 그림과 전체 셀을 유지한다. 오류 안내 옆의 **다시 시도**로 현재 세대·필터의 로드를 다시 요청할 수 있다. 하나의 아이콘 시트를 로드할 때 일반·이로치 캐시를 함께 만들며, 혼합 목록에서도 각 칸에는 해당 색상 비트맵만 사용한다.
- 필터 결과가 비면 보유한 포켓몬이 없다는 안내를 표시한다. 이로치 조회에서는 이로치 안내를 사용한다.
- 세대나 색상을 빠르게 전환한 경우 이전 요청 결과는 현재 목록에 적용하지 않는다.

## 도감·박스와 필터

- **도감**은 기존의 전체 목록과 보유 필터를 제공한다. **박스**는 같은 세대·색상 선택을 사용하면서 보유한 모습만 표시한다. 박스에 들어가면 **보유만**이 체크된 채 비활성화되고, 도감으로 돌아오면 박스에 들어가기 전의 보유 필터를 복원한다. 탭 전환 시 목록 스크롤은 맨 위로 돌아간다.
- 기본값은 **혼합 목록**이다. 일반 종의 칸을 표시하고 실제 보유한 이로치를 같은 번호의 일반 칸 바로 다음에 추가한다. 이로치를 보기 위해 체크박스를 켤 필요가 없다.
- **보유만**을 켜면 일반·이로치 양쪽에서 실제 보유한 `번호 + 색상` 칸만 남긴다. 일반 미보유·이로치 보유인 종도 이로치 칸은 표시한다. 필터를 꺼도 보유 이로치 칸은 유지된다.
- 별 모양 **이로치만**을 켜면 이로치 1,036개 모습을 기준으로 표시한다. **보유만**도 켜면 보유 이로치만 남긴다. 필터 해제 시 혼합 목록으로 돌아간다.
- 필터 변경은 메인 포켓몬과 선택 색상을 바꾸지 않는다. 일반과 이로치의 레벨·경험치·이미지를 합치거나 서로 대체하지 않는다.
- 혼합 목록 보유 수는 `(Owned.Count + ShinyOwned.Count)/2072`, 이로치만 목록은 `ShinyOwned.Count/1036`다. 세대별 수가 아니라 전체 실제 보유 수이며 같은 종의 두 색상을 별도로 센다.
- Debug 전체 해금은 실제 보유 수를 늘리지 않는다. 혼합 목록에 추가하는 이로치도 실제 `ShinyOwned` 기준이다.

## 포켓몬 선택

1. 보유 셀을 누르면 해당 색상의 본체 스프라이트를 비동기로 로드한다.
2. 로드가 성공한 뒤 `SelectedDex`, `SelectedShiny`, 레벨과 경험치 표시를 바꾼다.
3. 선택 상태를 즉시 저장하고 노란 테두리를 새 셀로 옮긴다.
4. 새 선택이 해당 회차의 현재 출발 모습이고 조건을 만족하면 진화를 자동으로 진행한다. 분기는 같은 색상의 미수집 직접 후보 중 무작위로 정하고 이미지 로딩 전에 저장한다. 이전 모습을 선택한 경우에는 다음 출발 모습으로 안내한다.
5. 스프라이트 로드가 실패하면 오류 메시지를 표시하고 기존 선택·레벨·본체 그림을 유지한다.

빠르게 여러 셀을 누르면 이전 요청 결과를 버리고 마지막 요청만 반영한다. 부화나 진화로 보유 상태가 바뀌면 현재 세대 또는 전체 목록과 보유 수를 갱신한다. 혼합 목록에서는 어느 색상이 추가되어도 새 칸이 즉시 나타난다. 이로치만 필터에서는 이로치 변경만 반영한다.

진화 연출 중에도 보유 셀을 선택할 수 있다. 현재 연출의 취소와 정리가 끝난 뒤 새 선택을 로드하며, 이전 연출이나 늦게 끝난 이미지 요청이 새 선택을 덮지 않는다. 진화 완료 저장 전의 취소는 예약 대상만 유지하고 새 모습을 지급하지 않는다. 완료 저장 후의 취소는 이미 얻은 모습·회차 성장을 유지하며 새로 선택한 포켓몬을 표시한다. 필터나 세대만 바꾸는 동작은 포켓몬 선택을 바꾸지 않는다.

## 선택 상세와 진화

- 혼합 목록 상세는 현재 선택한 일반 또는 이로치를 그대로 표시한다. **이로치만**을 켰는데 현재 선택이 일반인 경우에만 이로치 포켓몬을 선택하라는 안내를 표시한다. 선택 자체는 바꾸지 않는다.
- 전국도감 번호는 `No.0004`, 타입은 `불꽃` 또는 `풀 · 독` 형식이다. 상세 헤더의 성장 툴팁은 `Lv.n · 경험치 현재/필요` 형식이다. 지역 모습도 원종의 번호를 쓰므로 내부 ID 4052의 가라르 나옹은 `No.0052`로 표시한다.
- 한글 이름·타입·설명은 앱에 포함된 데이터를 사용한다. 원본에 한글 도감 문장이 없는 `#899~#1025` 127종과 지역 모습 11개는 출처의 한글 분류·해당 모습의 실제 타입으로 설명한다. 임의의 도감 문장을 만들거나 다른 모습의 문장을 붙이지 않는다.
- 진화해도 이전 모습의 보유는 남는다. 같은 육성 회차의 이전·현재 모습은 레벨·경험치를 공유하며, 일반과 이로치 또는 별도 회차는 공유하지 않는다. 예전 저장에 있던 서로 다른 성장 기록을 임의로 합치지 않는다.
- 이전 모습을 선택 중이고 현재 회차의 다음 진화가 준비되면 상단 안내를 누를 때 출발 모습의 색상·세대 도감을 연다. 강조된 출발 모습을 선택하면 다음 단계로 진화한다.
- 분기는 미수집 직접 후보 중 균등 무작위다. 이브이는 Lv.25에 8개 진화형 중 하나로 진화하며, 진화형은 새 알 후보에서 제외한다. 이미 보유한 진화형과 구버전에서 확정된 진화형 알은 유지한다.
