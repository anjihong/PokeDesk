# 도감과 포켓몬 선택

- **도감** 탭을 누르면 서랍이 열리고 다시 누르면 닫힌다. **메뉴 2**, **메뉴 3**은 화면에 있지만 비활성 상태다.
- 도감은 1~9세대 탭으로 구분하며 전국도감 `#1~#1025`를 대상으로 한다. 아이콘은 해당 세대의 아틀라스를 읽어 격자에 배치한다.
- **이로치 도감**을 켜면 이로치 아이콘·보유 목록으로 전환한다. 도감 전환만으로 현재 화면의 포켓몬은 바뀌지 않는다.
- 보유 종은 원본 아이콘과 `#번호 이름 · Lv.n` 툴팁으로 표시하고 선택할 수 있다. 미보유 종은 어두운 실루엣과 `#번호 ??? (미보유)` 툴팁으로 표시하며 선택할 수 없다.
- **보유만 보기**는 현재 보고 있는 일반 또는 이로치 도감에 적용된다. 우측 보유 수 역시 현재 색상 기준 `1025`종 대비 수치다.
- 보유 아이콘을 선택하면 해당 색상의 스프라이트와 레벨 표시가 바뀌고 선택 상태를 즉시 저장한다. 스프라이트 로드에 실패하면 메시지를 보여주고 이전 선택으로 되돌린다. 빠르게 연속 선택한 경우에는 가장 최신 로드 요청만 화면에 반영한다.
- 부화 결과는 같은 색상의 도감 셀과 보유 수에 반영된다. 같은 종이어도 일반과 이로치는 별도 개체로 취급한다.
