# 이로치 획득, 도감 및 성장

## 기능 범위

이로치는 같은 도감 번호의 일반 포켓몬과 다른 개체로 취급한다. 보유 여부, 레벨, 경험치, 선택 상태, 도감 아이콘과 본체 스프라이트를 모두 독립 관리한다.

현재 이로치 획득 경로는 알 부화뿐이다. 스타팅 선택에서 이로치는 나오지 않는다.

## 획득 확률

| 알 종류 | 알 생성 확률 | 해당 알에서 이로치 확률 | 전체 알 기준 기여 확률 |
| --- | ---: | ---: | ---: |
| 커먼 | 47.5% | 7% | 3.325% |
| 레어 | 30% | 7% | 2.1% |
| 에픽 | 15% | 7% | 1.05% |
| 레전더리 | 5% | 7% | 0.35% |
| 이로치알 | 2.5% | 100% | 2.5% |
| 합계 | 100% | - | **9.325%** |

- 커먼·레어·에픽·레전더리 알은 종을 먼저 고른 뒤 7% 확률로 이로치 여부를 판정한다.
- 정확히 7% 경계값은 실패로 처리하고 7%보다 작은 난수만 성공으로 처리한다.
- 이로치알은 선택된 종을 항상 이로치로 만든다.
- 이로치알의 종은 일반·특수 구분 없이 전체 `BaseSpecies.Dex`에서 균등 추첨한다.
- 다른 등급의 종 선택 규칙은 [06-egg.md](06-egg.md)를 따른다.
- Debug 테스트 메뉴에서는 모든 등급을 강제로 이로치로 만들 수 있다. 실제 확률과 저장 구조는 바뀌지 않는다.

## 결과 사전 확정

이로치 여부는 알을 클릭하는 순간이 아니라 `PendingEgg`를 만들 때 확정한다.

1. 새 게임 생성 또는 이전 알 부화 직후 다음 알을 만든다.
2. 알 등급과 종을 뽑는다.
3. 이로치 여부를 판정한다.
4. `Kind`, `Dex`, `IsShiny`를 저장한다.
5. 30분 대기와 앱 재시작 동안 같은 결과를 유지한다.

알을 받을 때나 부화할 때 다시 추첨하지 않으므로 앱 재시작으로 결과를 바꿀 수 없다.

## 보유 및 성장 분리

| 항목 | 일반 | 이로치 |
| --- | --- | --- |
| 보유 목록 | `Owned` | `ShinyOwned` |
| 성장 기록 | `Progress[dex]` | `ShinyProgress[dex]` |
| 현재 선택 색상 | `SelectedShiny = false` | `SelectedShiny = true` |
| 도감 아이콘 | 일반 프레임 | 이로치 프레임 |
| 본체 스프라이트 | 일반 경로 | 이로치 경로 |

예를 들어 일반 피카츄를 보유해도 이로치 피카츄는 미보유 상태다. 이로치 피카츄를 처음 부화하면 이로치 도감에 신규 등록하고 `NEW!`를 표시한다.

- 같은 이로치를 다시 부화하면 이로치 레벨만 1 오른다.
- 같은 종의 일반 레벨과 경험치는 변하지 않는다.
- 중복 이로치의 기존 경험치는 유지한다.
- 이로치를 선택한 상태에서 발생한 전역 입력은 이로치 경험치만 올린다.
- 일반과 이로치 모두 처음 등록될 때 기본 레벨은 1, 경험치는 0이다.

## 도감 동작

### 이로치 도감 전환

- **이로치 도감** 체크박스를 켜면 현재 세대 목록을 이로치 기준으로 다시 만든다.
- 일반·이로치 전환은 도감의 조회 모드만 바꾼다. 메인 화면의 현재 포켓몬은 자동으로 바꾸지 않는다.
- **보유만 보기**는 현재 조회 중인 색상에만 적용된다.
- 보유 수는 `ShinyOwned.Count/1025`로 표시한다.
- 미보유 이로치는 이로치 아이콘을 바탕으로 만든 실루엣과 `#번호 ??? ★ 이로치 (미보유)` 툴팁으로 표시한다.
- 보유 이로치는 `#번호 이름 ★ 이로치 · Lv.n` 툴팁으로 표시한다.

### 이로치 선택

1. 보유한 이로치 셀을 누른다.
2. 이로치 본체 스프라이트를 로드한다.
3. 성공하면 `SelectedDex`와 `SelectedShiny = true`를 저장한다.
4. 메인 레벨 앞에 `★`를 표시하고 이로치 레벨·경험치로 바꾼다.
5. 이후 입력 경험치는 해당 이로치에 적용한다.

스프라이트 로드가 실패하면 선택을 바꾸지 않는다. 도감 체크박스를 일반으로 되돌려도 이미 선택한 이로치는 메인 화면에 계속 남는다.

## 부화 결과 표시

- 신규 이로치는 `NEW!`를 표시한다.
- 중복 이로치는 상승한 `Lv.n ↑`를 표시한다.
- 말풍선에는 첫 줄에 `★ 이로치`, 둘째 줄에 포켓몬 이름을 표시한다.
- 현재 선택 중인 같은 이로치가 중복 부화하면 메인 레벨 표시도 즉시 갱신한다.
- 현재 보고 있는 이로치 도감의 같은 세대 셀과 전체 이로치 보유 수를 즉시 갱신한다.
- 부화 저장이 실패하면 이로치 보유·레벨 변경을 되돌리고 알을 유지한다.

## 이미지 로드

### 본체 스프라이트

1. PokéRogue `pokemon/exp/shiny/`, `pokemon/shiny/` 순서로 첫 아틀라스를 찾는다.
2. 아틀라스가 여러 프레임이면 즉시 사용한다.
3. 아틀라스가 정지 프레임이거나 없으면 PokeAPI 5세대 BW 이로치 GIF를 시도한다.
4. 정지 아틀라스는 있지만 GIF가 없으면 해당 정지 아틀라스를 사용한다.
5. 아틀라스와 GIF가 모두 없으면 PokeAPI 이로치 정지 PNG를 사용한다.

이로치 이미지가 없다고 일반 이미지로 대체하지 않는다. 색상 오표시를 막기 위한 규칙이다. 모든 이로치 소스가 실패하면 로드 실패를 표시하거나 이전 선택을 유지한다.

### 도감 아이콘

- 세대별 PokéRogue 아이콘 시트에서 도감 번호 뒤에 `s`가 붙은 이로치 프레임을 읽는다.
- 일반·이로치 아이콘은 같은 시트 다운로드와 디코딩을 공유하지만 메모리 캐시는 분리한다.
- 실루엣 캐시도 `도감 번호 + 색상` 조합으로 분리한다.

## 저장과 마이그레이션

- 저장 스키마 2부터 `SelectedShiny`, `ShinyOwned`, `ShinyProgress`, `PendingEgg.IsShiny`를 기록한다.
- 스키마 1 데이터는 이로치 보유·성장 목록을 빈 상태로 만든다. 기존 일반 데이터는 유지한다.
- 마이그레이션은 이로치를 임의 지급하지 않는다.
- 구버전의 현재 선택은 일반으로 복원한다.
- 저장된 이로치 선택이 실제 `ShinyOwned`에 없으면 일반 스타팅으로 복구한다.
- 선택 색상은 앱 재시작 후에도 유지한다.

저장 필드와 원자적 저장 규칙은 [07-save-data.md](07-save-data.md)를 참고한다.

## 현재 제한

- 야생 조우, 교환, 진화로 이로치를 얻는 기능은 없다.
- 일반과 이로치 사이의 성장 공유나 변환 기능은 없다.
- 이로치 확률을 설정에서 변경할 수 없다.
- 이로치알 전용 사용자 제작 이미지는 없다. 현재 PokéRogue 마나피 알 프레임을 사용한다.
