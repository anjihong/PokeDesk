# 이로치 획득, 도감 및 성장

## 기능 범위

이로치는 같은 도감 번호의 일반 포켓몬과 다른 개체로 취급한다. 보유 여부, 레벨, 경험치, 선택 상태, 도감 아이콘과 본체 스프라이트를 모두 독립 관리한다.

이로치는 알 부화로 처음 획득하고, 보유한 이로치를 진화해 같은 색상의 다음 단계를 얻을 수 있다. 스타팅 선택에서 이로치는 나오지 않는다.

## 획득 확률

| 알 종류 | 알 생성 확률 | 해당 알에서 이로치 확률 | 전체 알 기준 기여 확률 |
| --- | ---: | ---: | ---: |
| 커먼 | 47.5% | 7% | 3.325% |
| 레어 | 30% | 7% | 2.1% |
| 에픽 | 15% | 7% | 1.05% |
| 레전더리 | 5% | 7% | 0.35% |
| 이로치알 | 2.5% | 100% | 2.5% |
| 합계 | 100% | - | **9.325%** |

- 커먼·레어·에픽·레전더리 알은 종을 먼저 고른 뒤 7% 확률로 이로치 여부를 판정한다.
- 정확히 7% 경계값은 실패로 처리하고 7%보다 작은 난수만 성공으로 처리한다.
- 이로치알은 선택된 종을 항상 이로치로 만든다.
- 이로치알의 종은 일반·특수 구분 없이 전체 `EvolutionData.EggPool`에서 균등 추첨한다.
- 다른 등급의 종 선택 규칙은 [06-egg.md](06-egg.md)를 따른다.
- Debug 테스트 메뉴에서는 모든 등급을 강제로 이로치로 만들 수 있다. 실제 확률과 저장 구조는 바뀌지 않는다.

## 결과 사전 확정

이로치 여부는 알을 클릭하는 순간이 아니라 `PendingEgg`를 만들 때 확정한다.

1. 새 게임 생성 또는 이전 알 부화 직후 다음 알을 만든다.
2. 알 등급과 종을 뽑는다.
3. 이로치 여부를 판정한다.
4. `Kind`, `Dex`, `IsShiny`를 저장한다.
5. 30분 대기와 앱 재시작 동안 같은 결과를 유지한다.

알을 받을 때나 부화할 때 다시 추첨하지 않으므로 앱 재시작으로 결과를 바꿀 수 없다.

## 보유 및 성장 분리

| 항목 | 일반 | 이로치 |
| --- | --- | --- |
| 보유 목록 | `Owned` | `ShinyOwned` |
| 성장 기록 | `Progress[GrowthLinks[id]]` | `ShinyProgress[ShinyGrowthLinks[id]]` |
| 회차·분기 이력 | 일반 회차의 `CurrentDex`, `History`, `PendingEvolution` | 이로치 회차의 별도 값 |
| 현재 선택 색상 | `SelectedShiny = false` | `SelectedShiny = true` |
| 도감 아이콘 | 일반 프레임 | 이로치 프레임 |
| 본체 스프라이트 | 일반 경로 | 이로치 경로 |

예를 들어 일반 피츄를 보유해도 이로치 피츄는 미보유 상태다. 이로치 피츄를 처음 부화하면 이로치 도감에 신규 등록하고 `NEW!`를 표시한다.

- 같은 이로치 기본형을 다시 부화하면 이로치 회차의 레벨만 1 오른다. 이미 분기를 거쳤고 미수집 이로치 가지가 남았다면 기본형에 새 Lv.1·경험치 0 회차를 연결한다.
- 같은 종의 일반 레벨과 경험치는 변하지 않는다.
- 레벨 보너스는 이로치 회차의 경험치를 유지한다. 재육성은 새 기본형만 초기화하며 이전 이로치 진화체의 성장은 유지한다.
- 이로치를 선택한 상태에서 발생한 전역 입력은 이로치 경험치만 올린다.
- 일반과 이로치 모두 알로 처음 등록될 때 기본 레벨은 1, 경험치는 0이다. 진화로 등록될 때는 같은 색상의 성장 기록을 계승한다.

## 색상별 진화와 재육성

- 일반과 이로치는 각각의 육성 회차 레벨로 조건을 판정한다. 반대 색상의 높은 레벨이나 보유를 가져오지 않는다.
- 진화 결과도 같은 색상이며, 같은 회차에서 거친 모습들은 레벨·경험치를 공유한다. **이로치 파이리 → 이로치 리자드 → 이로치 리자몽**의 세 도감 칸은 유지되고 일반 세 형태의 보유·성장은 바뀌지 않는다.
- 분기 결과는 해당 색상의 미수집 후보 중 균등 무작위로 선택하고 이미지 로딩 전에 저장한다. 실패·재시작에도 같은 대상을 유지한다.
- 분기 기본형 재부화는 같은 색상의 분기 이력과 보유만 확인한다. 이전 진화체는 기존 회차에 남고 새 기본형은 독립 회차로 다시 자란다.
- 일반 이브이 진화체 8종을 모두 모았더라도 이로치 이브이는 8종을 따로 모아야 한다. 이브이는 Lv.25에 진화하며 진화체는 새 알에서 직접 나오지 않는다.
- 일반에서 이로치로 또는 반대로 색상을 바꾸는 기능은 없다. 상세 조건과 지역 모습은 [11-evolution.md](11-evolution.md)를 따른다.

## 도감 동작

### 기본 혼합 목록과 이로치만 필터

- 기본 도감은 일반과 실제 보유한 이로치를 함께 표시한다. 같은 번호의 일반 칸 바로 다음에 이로치 칸을 두며 이로치에는 **★ 배지**를 붙인다.
- **보유만**을 켠 기본 목록은 양쪽 보유 목록의 합집합이다. 같은 번호라도 일반과 이로치를 독립된 두 칸으로 취급한다. 일반을 보유하지 않아도 보유 이로치는 나타난다.
- **이로치만** 체크박스는 선택적 필터다. 켜면 현재 세대 또는 전체 1,036개 모습의 이로치 칸을 표시하고, **보유만**도 켜면 보유 이로치만 표시한다. 끄면 혼합 목록으로 돌아간다.
- 필터 변경은 메인 화면의 선택을 바꾸지 않는다. 혼합 목록의 이로치 칸을 바로 눌러 이로치를 선택할 수 있다.
- 기본 보유 수는 `(Owned.Count + ShinyOwned.Count)/2072`, 이로치만 필터는 `ShinyOwned.Count/1036`다. Debug 전체 해금으로 실제 보유 수를 늘리지 않는다.
- 미보유 이로치는 이로치만 목록에서 이로치 실루엣과 `#번호 ??? ★ 이로치 (미보유)` 툴팁으로 표시한다. 기본 혼합 목록에는 미보유 이로치 칸을 추가하지 않는다.
- 보유 이로치는 `#번호 이름 ★ 이로치 · Lv.n` 툴팁으로 표시한다. 진화 가능하면 칸을 강조하고 툴팁에 `· 진화 가능`을 붙인다.
- 아이콘이 없을 때도 해당 칸을 `?`로 유지하며, 일반 그림으로 대신하지 않는다. 두 색상의 아이콘은 같은 시트에서 읽지만 서로 다른 캐시 항목으로 유지한다.
- 혼합 목록의 상세 패널은 현재 선택한 이로치 이름·타입·설명과 이로치 성장 기록을 그대로 표시한다. 이로치만 필터인데 현재 선택이 일반인 경우에만 이로치를 선택하라는 안내를 표시한다.

### 이로치 선택

1. 보유한 이로치 셀을 누른다.
2. 이로치 본체 스프라이트를 로드한다.
3. 성공하면 `SelectedDex`와 `SelectedShiny = true`를 저장한다.
4. 메인 레벨 앞에 `★`를 표시하고 이로치 레벨·경험치로 바꾼다.
5. 이후 입력 경험치는 해당 이로치에 적용한다.

스프라이트 로드가 실패하면 선택을 바꾸지 않는다. **이로치만** 필터를 해제해도 선택한 이로치는 메인 화면과 혼합 목록 상세에 계속 표시된다.

## 부화 결과 표시

- 신규 이로치는 `NEW!`를 표시한다.
- 중복 이로치는 레벨 보너스 또는 새 Lv.1 재육성 결과를 구분해 표시한다.
- 말풍선에는 첫 줄에 `★ 이로치`, 둘째 줄에 포켓몬 이름을 표시한다.
- 현재 선택 중인 같은 이로치 회차에 중복 보너스나 재육성이 적용되면 메인 레벨 표시도 즉시 갱신한다.
- 기본 혼합 목록과 이로치만 목록 모두에서 현재 세대 또는 전체 목록을 즉시 갱신한다. 기본 목록을 보고 있을 때 새 이로치가 부화해도 필터 조작 없이 새 칸이 나타나며 실제 보유 수가 오른다.
- 부화 저장이 실패하면 이로치 보유·레벨·회차 연결을 되돌리고 알을 유지한다.

## 이미지 로드

### 본체 스프라이트

1. PokéRogue `pokemon/exp/shiny/`, `pokemon/shiny/` 순서로 첫 아틀라스를 찾는다.
2. 아틀라스가 여러 프레임이면 즉시 사용한다.
3. 아틀라스가 정지 프레임이거나 없으면 PokeAPI 5세대 BW 이로치 GIF를 시도한다.
4. 정지 아틀라스는 있지만 GIF가 없으면 해당 정지 아틀라스를 사용한다.
5. 아틀라스와 GIF가 모두 없으면 PokeAPI 이로치 정지 PNG를 사용한다.

지원 지역 모습은 PokéRogue의 해당 지역·색상 경로만 사용하며, 내부 ID를 PokeAPI 전국도감 번호로 넘겨 다른 모습을 대신 표시하지 않는다.

이로치 이미지가 없다고 일반 이미지로 대체하지 않는다. 색상 오표시를 막기 위한 규칙이다. 모든 이로치 소스가 실패하면 로드 실패를 표시하거나 이전 선택을 유지한다.

### 도감 아이콘

- 세대별 PokéRogue 아이콘 시트에서 도감 번호 뒤에 `s`가 붙은 이로치 프레임을 읽는다.
- 일반·이로치 아이콘은 같은 시트 다운로드와 디코딩을 공유하지만 메모리 캐시는 분리한다.
- 실루엣 캐시도 `도감 번호 + 색상` 조합으로 분리한다.

### 이로치알

이로치알은 `EggArtwork`에서 생성하는 `28×30px` 금색 별무늬 픽셀 알이다. 네 가지 일반 등급과 구분되며 외부 다운로드가 필요 없다. PokéRogue의 마나피 알 프레임을 이로치알로 사용하지 않는다.

## 저장과 마이그레이션

- 현재 스키마 3은 스키마 2의 색상 필드에 `ShinyGrowthLinks`와 회차별 현재 모습·이력·예약 진화를 추가한다. main 스키마 3과 같은 구조다.
- 스키마 1 데이터는 이로치 보유·성장 목록을 빈 상태로 만든다. 기존 일반 데이터는 유지한다.
- 마이그레이션은 이로치를 임의 지급하지 않는다.
- 스키마 1 이하의 현재 선택은 일반으로 복원한다. 스키마 2의 유효한 이로치 선택과 종별 성장 기록은 독립 회차로 그대로 유지한다.
- 저장된 이로치 선택이 실제 `ShinyOwned`에 없으면 일반 스타팅으로 복구한다.
- 선택 색상은 앱 재시작 후에도 유지한다.

저장 필드와 원자적 저장 규칙은 [07-save-data.md](07-save-data.md)를 참고한다.

## 현재 제한

- 야생 조우나 교환으로 이로치를 얻는 기능은 없다.
- 일반과 이로치 사이의 성장 공유나 변환 기능은 없다.
- 이로치 확률을 설정에서 변경할 수 없다.
