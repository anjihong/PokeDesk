# 개발용 기능과 이슈별 구현 상태

- Debug 빌드의 우클릭 메뉴에는 **테스트 알 즉시 지급**, **진화 테스트 모드**, **초기화(테스트)**, **전체 해금(치트)**, **배치 편집**, **배치 저장(소스 기본값)**, **배치 되돌리기**가 추가된다.
- 테스트 알 메뉴에서 등급을 지정하고 **이번 테스트 알 확정 이로치**를 선택할 수 있다. 기존 알은 교체된다. Release 빌드 우클릭 메뉴에는 **종료**만 있다.
- 초기화는 확인 후 저장 파일을 삭제하고 앱을 재시작한다. 전체 해금은 실행 중에만 모든 종을 선택 가능하게 하며 보유 목록에는 저장되지 않는다. 해제 시 미보유 종을 선택 중이었다면 스타팅으로 돌아간다.
- 배치 편집은 말풍선과 알 그룹을 드래그해 위치를 조정한다. 배치 저장은 `LayoutDefaults.cs`의 기본 오프셋 값을 수정하므로 다시 빌드해야 적용된다.

## 진화 수동 테스트

- **진화 테스트 모드**를 누르면 현재 저장을 마치고 앱을 다시 실행한다. 테스트 상태는 `%LOCALAPPDATA%/DeskPokemon/evolution-test.json`에 따로 저장하며 재실행 후에도 유지된다. 새 테스트 세이브는 파이리로 시작한다. 화면 상단에 테스트 모드 표시가 뜬다.
- 테스트 패널은 시작할 때 열리며, 닫은 뒤에는 우클릭 메뉴에서 다시 열 수 있다. 이름·도감 번호로 알 후보를 검색하고 **분기 계열 / 지역 모습 / 전체 알 후보**로 거른다. 일반·이로치를 정해 **지정 알 준비**를 누르면 기존 알을 교체한다. 실제 부화는 게임 화면의 알을 눌러 진행한다.
- **선택 중인 계열의 기본형 다시 준비**는 현재 선택한 육성 이력의 기본형과 색상으로 알을 준비한다. 분기 완료 후 새 Lv.1 육성, 분기 미완료·전체 수집 후 레벨 보너스를 이 버튼으로 확인한다.
- **다음 진화 레벨로 이동**은 선택한 모습에 연결된 육성을 다음 진화 조건까지 올리고 경험치는 보존한다. 레벨은 낮추지 않는다. 현재 진화 출발 모습을 선택 중이면 기존 진화 흐름이 시작된다. **이전 모습 선택** 후 레벨을 올리면 진화 알림과 도감 강조를 확인할 수 있다. 도감에서 강조된 출발 모습을 누르면 진화한다.
- 테스트 모드에서는 전역 입력 경험치를 기록하지 않는다. 알 준비·레벨 이동의 저장 실패 시 변경을 복구한다. **진화 테스트 세이브 초기화**는 테스트 파일만 삭제하고 다시 시작한다. **일반 모드로 돌아가기**는 실제 세이브를 다시 연다. Release 빌드에는 이 도구가 없다.
