# 개발용 기능과 이슈별 구현 상태

- Debug 빌드의 우클릭 메뉴에는 **진화 테스트 모드**, **테스트 알 즉시 지급**, **초기화(테스트)**, **전체 해금(치트)**, **배치 편집**, **배치 저장(소스 기본값)**, **배치 되돌리기**가 추가된다.
- 테스트 알 메뉴에서 등급을 지정하고 **이번 테스트 알 확정 이로치**를 선택할 수 있다. 기존 알은 교체된다. Release 빌드에는 이러한 개발 메뉴가 없으며 전역 입력 재연결, 포켓몬 그림 재시도와 종료 같은 일반 메뉴를 제공한다.
- 일반 모드 초기화는 확인 후 일반 저장 파일을 삭제하고 스타팅 선택 창으로 돌아간다. 전체 해금은 실행 중에만 모든 종을 선택 가능하게 하며 보유 목록에는 저장되지 않는다. 해제 시 미보유 종을 선택 중이었다면 스타팅으로 돌아간다.
- 배치 편집은 말풍선과 알 그룹을 드래그해 위치를 조정한다. 배치 저장은 `LayoutDefaults.cs`의 기본 오프셋 값을 수정하므로 다시 빌드해야 적용된다.

## 진화 수동 테스트 모드

- Debug 빌드에서 `--evolution-test` 인자 또는 우클릭 메뉴로 진입한다. Release 빌드에는 모드, 인자 처리, 별도 세이브 로더, 테스트 패널이 포함되지 않는다.
- 일반 `settings.json`과 같은 OS별 데이터 폴더의 `evolution-test.json`을 별도로 사용한다. 파일이 없으면 파이리로 시작하며, 손상된 테스트 파일은 덮어쓰지 않고 불러오기 오류를 표시한다. 일반 세이브를 읽거나 초기화하지 않는다.
- 메인 창에 **진화 테스트 모드 · 별도 세이브**를 표시하고 시작 준비 후 도구 패널을 연다. 패널을 닫아도 게임은 계속되며 우클릭 메뉴에서 다시 열 수 있다. 메인 창을 닫으면 패널과 상태 갱신 타이머도 정리한다.
- 외부 앱의 전역 입력 훅은 연결하지 않으며, 메인 게임 창 안의 키·클릭으로도 경험치가 오르지 않는다. 테스트 도구의 레벨 이동과 부화에 따른 성장은 그대로 적용한다. 알 시간 누적과 저장 등 게임 수명 주기는 유지한다.
- 알 후보를 **분기 계열 / 지역 모습 / 전체 알 후보**로 걸러 이름 또는 전국도감 번호로 검색한다. **지정 알 준비**는 선택한 종과 일반·이로치 색상을 확정한 알을 즉시 준비한다. 보유 종에 바로 추가하지 않으며 게임 화면의 알을 눌러 실제 부화를 확인한다.
- **선택 중인 계열의 기본형 다시 준비**는 현재 성장 기록의 첫 종과 같은 색상의 알을 준비한다. **다음 진화 레벨로 이동**은 선택한 색상의 성장 기록을 다음 조건 레벨 이상으로 올리고 실제 진화 흐름을 실행한다. **이전 모습 선택**은 현재 성장 회차에서 직전 모습으로 표시만 바꾸며 진화 완료나 성장을 되돌리지 않는다.
- 진화·부화·부화 결과 표시 중에는 알 교체나 성장 이동 버튼을 사용할 수 없다. 선택한 종·색상·레벨·현재 진화 단계와 다음 조건 레벨을 패널에서 확인한다.
- **일반 모드로 돌아가기**는 현재 저장 성공 후 같은 앱 수명 안에서 새 모드 창으로 전환한다. 저장에 실패하면 기존 창을 유지한다. **진화 테스트 세이브 초기화**는 확인 후 테스트 파일만 원자적으로 새 게임으로 교체하며 일반 파일은 보존한다. 두 OS에서 같은 Avalonia 패널과 확인 대화상자를 사용한다.
