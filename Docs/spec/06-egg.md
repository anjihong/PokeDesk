# 알 등급, 지급 및 부화

## 결과 확정과 지급

- 다음 알까지 앱 실행 시간 **30분**을 누적한다. 대기 중 말풍선에 남은 시간을 `mm:ss`로 표시한다.
- 앱이 꺼진 동안에는 시간이 흐르지 않는다. 1초 주기로 실제 경과 시간을 더하되 절전 등으로 틱이 지연돼도 한 번에 최대 5초만 인정한다.
- 알은 한 번에 최대 1개만 보유한다. 알을 보유한 동안 타이머는 멈추며, 부화 후 다음 30분 누적을 시작한다.
- 다음 알의 등급, 도감 번호, 이로치 여부는 대기 시작 전에 한 번만 추첨해 `PendingEgg`에 저장한다. 앱 재시작이나 타이머 완료 시 다시 추첨하지 않는다.
- 알이 준비되면 말풍선에 **클릭하여 부화**가 표시된다. 준비 전 클릭은 부화를 시작하지 않는다.

## 알 등급 확률

| 등급 | 생성 확률 | 일반 풀 | 특수 풀 | 이로치 확률 |
| --- | ---: | ---: | ---: | ---: |
| 커먼 | 47.5% | 100% | 0% | 7% |
| 레어 | 30% | 85% | 15% | 7% |
| 에픽 | 15% | 50% | 50% | 7% |
| 레전더리 | 5% | 0% | 100% | 7% |
| 이로치알 | 2.5% | 전체 후보 | 전체 후보 | 100% |

- 후보는 진화 전 단계 또는 진화하지 않는 종을 담은 `BaseSpecies.Dex`다.
- 특수 풀은 전설·환상·패러독스 포켓몬이다. 울트라비스트는 현재 일반 풀에 포함된다.
- 풀을 정한 뒤 그 안에서 모든 종을 같은 확률로 뽑는다. 이전의 포획률 가중치는 현재 사용하지 않는다.
- 이로치 여부는 종을 뽑은 뒤 판정한다. 커먼·레어·에픽·레전더리 알에서도 7% 확률로 이로치가 나온다.

## 부화 처리

1. 준비된 알을 클릭하면 흔들림, 균열, 플래시 애니메이션을 재생한다.
2. `PendingEgg`에 저장된 결과를 지급한다. 부화 시점에는 다시 추첨하지 않는다.
3. 해당 색상의 새 종이면 별도 도감에 등록하고 **NEW!**를 표시한다. 이미 보유한 같은 색상 종이면 그 개체의 레벨을 1 올리고 `Lv.n ↑`를 표시한다. 기존 경험치는 유지된다.
4. 결과 스프라이트와 이름을 로드 완료 후 약 5초간 보여준 뒤 다음 알 대기로 돌아간다. 스프라이트 로드가 실패하면 가능한 아이콘과 이름을 유지한다.
5. 부화 결과, 알 소비, 다음 `PendingEgg`를 한 번에 저장한다. 저장 실패 시 보유·레벨·알 상태를 되돌리고 기존 알을 유지한다.

알 등급마다 PokéRogue 알 프레임을 사용한다. 이미지나 균열 에셋을 가져오지 못하면 기본 타원형 알을 사용하고 균열 없이 부화를 진행한다. 등급별 즉시 지급은 Debug 빌드 전용이다.
