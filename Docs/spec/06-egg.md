# 알 등급, 지급 및 부화

## 결과 확정과 지급

- 다음 알까지 앱 실행 시간 **30분**을 누적한다. 대기 중 말풍선에는 남은 시간 `mm:ss`만 16 DIP 글자로 한 줄 표시한다.
- 앱이 꺼진 동안에는 시간이 흐르지 않는다. 1초 주기로 실제 경과 시간을 더하되 절전 등으로 틱이 지연돼도 한 번에 최대 5초만 인정한다.
- 알은 한 번에 최대 1개만 보유한다. 알을 보유한 동안 타이머는 멈추며, 부화 후 다음 30분 누적을 시작한다.
- 다음 알의 등급, 도감 번호, 이로치 여부는 대기 시작 전에 한 번만 추첨해 `PendingEgg`에 저장한다. 앱 재시작이나 타이머 완료 시 다시 추첨하지 않는다.
- 알이 준비되면 말풍선에 **클릭하여 부화**를 11 DIP 글자로 한 줄 표시한다. 준비 전 클릭은 부화를 시작하지 않는다.

`PendingEgg`가 가리키는 알 외형은 30분 대기 중에도 표시된다. 등급 이름은 알과 말풍선에 마우스를 올렸을 때 툴팁으로 제공한다. 사용자는 다음 알의 등급을 미리 알 수 있지만 종과 이로치 여부는 부화 전까지 화면에 표시되지 않는다.

## 상태 전이

| 상태 | 화면 | 사용자 동작 | 다음 상태 |
| --- | --- | --- | --- |
| 대기 | 등급별 알, 남은 `mm:ss` | 알 클릭은 무시 | 30분 누적 후 준비 |
| 준비 | **클릭하여 부화** 한 줄, 반복 흔들림 | 알 클릭 | 부화 중 |
| 부화 중 | 16 DIP `...`, 흔들림·균열·플래시 | 추가 클릭 무시 | 저장 성공 시 결과 |
| 결과 | 11 DIP 포켓몬 이름·스프라이트·신규·레벨 상승·재육성 표시 | 추가 클릭 무시 | 표시 종료 후 대기 |

결과 표시는 이미지 로드가 끝난 시점부터 약 5초다. 긴 이름은 말풍선 안에서 자동 줄바꿈하고 이로치 결과의 `★ 이로치` 줄은 유지한다. 다음 알의 대기 시간이 흐르더라도 결과 문구를 덮지 않는다. 로드 실패 시 확보한 아이콘이나 이름만으로 결과를 표시한다.

## 알 등급 확률

| 등급 | 생성 확률 | 일반 풀 | 특수 풀 | 이로치 확률 |
| --- | ---: | ---: | ---: | ---: |
| 커먼 | 47.5% | 100% | 0% | 7% |
| 레어 | 30% | 85% | 15% | 7% |
| 에픽 | 15% | 50% | 50% | 7% |
| 레전더리 | 5% | 0% | 100% | 7% |
| 이로치알 | 2.5% | 전체 후보 | 전체 후보 | 100% |

- 새 알 후보는 `EvolutionData.EggPool`의 **550개 기본 모습**이다. 기본 1,025종과 지원 지역 모습 11개를 진화로 모두 획득할 수 있도록 계열의 시작 모습만 포함한다. `BaseSpecies.Dex`는 같은 목록을 제공한다.
- 이브이는 알 후보이며 Lv.25에 8갈래로 진화한다. 샤미드·쥬피썬더·부스터·에브이·블래키·리피아·글레이시아·님피아는 새 알 후보에서 제외한다. 구버전에서 이미 확정된 진화형 알은 결과를 바꾸지 않고 한 번 부화할 수 있다.
- 가라르 나옹·지그제구리, 팔데아 우파 등 지원 지역 계열의 기본 모습도 후보에 포함한다. 이미 진화한 지역 모습은 직접 알에서 나오지 않는다.
- 특수 풀은 전설·환상·패러독스 포켓몬이다. 울트라비스트는 현재 일반 풀에 포함된다.
- 풀을 정한 뒤 그 안에서 모든 종을 같은 확률로 뽑는다. 이전의 포획률 가중치는 현재 사용하지 않는다.
- 이로치 여부는 종을 뽑은 뒤 판정한다. 커먼·레어·에픽·레전더리 알에서도 7% 확률로 이로치가 나온다.
- 무작위 알 전체를 기준으로 이로치가 나올 확률은 `2.5% + 97.5% × 7% = 9.325%`다.

추첨 순서는 다음과 같다.

1. 5개 알 등급 중 하나를 뽑는다.
2. 등급 규칙에 따라 일반 풀 또는 특수 풀을 고른다.
3. 선택된 풀에서 종 하나를 균등 추첨한다.
4. 이로치알이면 이로치를 확정한다. 다른 등급이면 7% 확률을 별도로 판정한다.
5. 등급, 종, 색상을 `PendingEgg`에 저장한다.

## 부화 처리

1. 준비된 알을 클릭하면 흔들림, 균열, 플래시 애니메이션을 재생한다.
2. `PendingEgg`에 저장된 결과를 지급한다. 부화 시점에는 다시 추첨하지 않는다.
3. 해당 색상의 새 모습이면 별도 도감에 등록하고 **NEW!**를 표시한다. 중복이면 아래 재육성 조건을 확인해 새 Lv.1 회차 또는 기존 회차의 레벨 +1을 적용한다. 레벨 보너스는 경험치를 유지한다.
4. 결과 스프라이트와 이름을 로드 완료 후 약 5초간 보여준 뒤 다음 알 대기로 돌아간다. 스프라이트 로드가 실패하면 가능한 아이콘과 이름을 유지한다.
5. 부화 결과, 알 소비, 다음 `PendingEgg`를 한 번에 저장한다. 저장 실패 시 보유·회차 연결·성장·알 상태를 모두 되돌리고 기존 알을 유지한다.

커먼·레어·에픽·레전더리는 PokéRogue의 해당 등급 프레임을 사용한다. 이로치알은 main에서 추가한 **`Assets/shiny-egg.png`의 28×30 원본 픽셀**을 그대로 사용하며 마나피 알 프레임으로 대체하지 않는다. 모든 알은 균열 연출과 맞도록 28×30 영역에 배치한다. 다운로드하는 알 이미지나 균열 에셋을 가져오지 못하면 기본 타원형 또는 균열 없는 연출로 부화를 계속한다. 등급별 즉시 지급은 Debug 빌드 전용이다.

- 이로치알은 대기·준비 상태에서만 `Assets/shiny-egg-sparkles.png`의 12개 프레임을 100ms 간격으로 반복한다. 40×38 효과를 알 기준 `(-6, -6)`에 배치하고 알과 함께 확대한다. 효과는 클릭을 가로채지 않는다.
- 알 본체와 반짝임은 앱에 포함되어 오프라인에서도 표시된다. 효과를 읽지 못해도 알 본체·부화 동작은 유지한다.
- 부화 시작·결과 표시·알 교체·창 종료 시 반짝임을 숨기고 타이머와 화면 참조를 정리한다. 이전 비동기 알 로드가 새로운 상태를 덮지 못하도록 요청을 무효화한다.
- 효과 조건은 `PendingEgg.Kind == Shiny`다. 다른 네 등급에서 7% 추첨이나 Debug 강제로 이로치 보상이 확정되어도 원래 등급 외형을 유지하고 반짝임을 표시하지 않는다.

## 중복, 재육성 및 색상 처리

| 같은 색상 기본형의 부화 직전 상태 | 결과 |
| --- | --- |
| 미보유 | 새 Lv.1·경험치 0 회차, `NEW!` |
| 현재 회차에서 아직 분기를 거치지 않음 | 현재 회차 레벨 +1, 경험치 유지 |
| 현재 회차에서 분기를 거쳤고 같은 색상 미수집 가지가 남음 | 기본형만 새 Lv.1·경험치 0 회차로 재육성 |
| 모든 가지를 수집했거나 비분기 계열 | 현재 회차 레벨 +1, 경험치 유지 |

- 재육성은 분기 대상 자체를 획득했는지로 판정한다. 개무소→실쿤만 진행했어도 카스쿤을 아직 얻지 못했다면 다음 개무소 알로 새 회차를 시작한다.
- 이전 진화체의 보유와 성장 기록은 유지한다. 랄토스 재육성 시 기존 킬리아는 이전 가디안 회차에 남고, 새 랄토스가 킬리아에 도달할 때 새 회차로 연결한다.
- 같은 육성 회차에서 거친 모습들은 경험치를 공유한다. 중복 알의 레벨 보너스도 해당 회차에 적용된다.
- 일반과 이로치는 보유, 회차, 분기 완료 여부를 따로 판정한다. 일반 진화체를 모두 모아도 이로치 재육성 후보가 줄지 않는다.
- 중복 레벨 보너스로 진화 조건을 처음 충족하면 레벨을 올린 뒤 진화한다. 그 부화에서 곧바로 재육성으로 초기화하지 않는다.
- 부화 후 현재 선택한 모습이 해당 회차의 진화 출발 모습이면 자동으로 한 단계씩 진화한다. 이전 모습을 선택 중이면 출발 모습으로 이동하는 안내를 표시한다. 분기는 미수집 후보에서 무작위 확정한다.
- 진화는 알이나 다음 `PendingEgg`를 바꾸지 않는다. 진화 중 알 클릭과 부화 연출 중 진화 시작은 막는다. 부화 결과 화면은 메인 진화와 별개로 자신이 부화한 종·색상을 표시한다.

이로치 표시 규칙은 [10-shiny.md](10-shiny.md), 공유 회차와 이브이·지역 모습의 진화 규칙은 [11-evolution.md](11-evolution.md)를 참고한다.
