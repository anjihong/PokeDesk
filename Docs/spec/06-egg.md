# 알 등급, 지급 및 부화

## 결과 확정과 지급

- 다음 알까지 앱 실행 시간 **30분**을 누적한다. 대기 중 말풍선에 남은 시간을 `mm:ss`로 표시한다.
- 앱이 꺼진 동안에는 시간이 흐르지 않는다. 1초 주기로 실제 경과 시간을 더하되 절전 등으로 틱이 지연돼도 한 번에 최대 5초만 인정한다.
- 알은 한 번에 최대 1개만 보유한다. 알을 보유한 동안 타이머는 멈추며, 부화 후 다음 30분 누적을 시작한다.
- 다음 알의 등급, 도감 번호, 이로치 여부는 대기 시작 전에 한 번만 추첨해 `PendingEgg`에 저장한다. 앱 재시작이나 타이머 완료 시 다시 추첨하지 않는다.
- 알이 준비되면 말풍선에 **클릭하여 부화**가 표시된다. 준비 전 클릭은 부화를 시작하지 않는다.

`PendingEgg`가 가리키는 알 외형과 등급 이름은 30분 대기 중에도 표시된다. 따라서 사용자는 다음 알의 등급을 미리 알 수 있지만 종과 이로치 여부는 부화 전까지 화면에 표시되지 않는다.

## 상태 전이

| 상태 | 화면 | 사용자 동작 | 다음 상태 |
| --- | --- | --- | --- |
| 대기 | 등급별 알, 남은 `mm:ss` | 알 클릭은 무시 | 30분 누적 후 준비 |
| 준비 | 등급 이름, **클릭하여 부화**, 반복 흔들림 | 알 클릭 | 부화 중 |
| 부화 중 | `...`, 흔들림·균열·플래시 | 추가 클릭 무시 | 저장 성공 시 결과 |
| 결과 | 포켓몬 이름·스프라이트·`NEW!`, 레벨 상승 또는 `새 육성 · Lv.1` | 추가 클릭 무시 | 표시 종료 후 대기 |

결과 표시는 이미지 로드가 끝난 시점부터 약 5초다. 로드 실패 시 확보한 아이콘이나 이름만으로 결과를 표시한다.

## 알 등급 확률

| 등급 | 생성 확률 | 일반 풀 | 특수 풀 | 이로치 확률 |
| --- | ---: | ---: | ---: | ---: |
| 커먼 | 47.5% | 100% | 0% | 7% |
| 레어 | 30% | 85% | 15% | 7% |
| 에픽 | 15% | 50% | 50% | 7% |
| 레전더리 | 5% | 0% | 100% | 7% |
| 이로치알 | 2.5% | 전체 후보 | 전체 후보 | 100% |

- 후보는 `EvolutionData.EggPool`의 550개 항목이다. 기존 기본형 541종(이브이 포함)과 추가 모습의 기본형 9개를 포함한다. 이브이 진화체 8종과 가라르 직구리·마임맨은 새 알 후보가 아니다. 이전 버전에서 이미 확정된 이브이 진화체 알은 그대로 부화할 수 있다.
- 특수 풀은 전설·환상·패러독스 포켓몬이다. 울트라비스트는 현재 일반 풀에 포함된다.
- 풀을 정한 뒤 그 안에서 모든 종을 같은 확률로 뽑는다. 이전의 포획률 가중치는 현재 사용하지 않는다.
- 이로치 여부는 종을 뽑은 뒤 판정한다. 커먼·레어·에픽·레전더리 알에서도 7% 확률로 이로치가 나온다.
- 무작위 알 전체를 기준으로 이로치가 나올 확률은 `2.5% + 97.5% × 7% = 9.325%`다.

추첨 순서는 다음과 같다.

1. 5개 알 등급 중 하나를 뽑는다.
2. 등급 규칙에 따라 일반 풀 또는 특수 풀을 고른다.
3. 선택된 풀에서 종 하나를 균등 추첨한다.
4. 이로치알이면 이로치를 확정한다. 다른 등급이면 7% 확률을 별도로 판정한다.
5. 등급, 종, 색상을 `PendingEgg`에 저장한다.

## 부화 처리

1. 준비된 알을 클릭하면 흔들림, 균열, 플래시 애니메이션을 재생한다.
2. `PendingEgg`에 저장된 결과를 지급한다. 부화 시점에는 다시 추첨하지 않는다.
3. 해당 색상의 새 종이면 별도 도감에 등록하고 **NEW!**를 표시한다. 이미 보유한 같은 색상 종은 보통 레벨을 1 올리고 `Lv.n ↑`를 표시한다. 분기 완료·미수집 가지가 남아 있는 기본형은 새 육성을 Lv.1·경험치 0으로 시작하고 `새 육성 · Lv.1`을 표시한다.
4. 결과 스프라이트와 이름을 로드 완료 후 약 5초간 보여준 뒤 다음 알 대기로 돌아간다. 스프라이트 로드가 실패하면 가능한 아이콘과 이름을 유지한다.
5. 부화 결과, 알 소비, 다음 `PendingEgg`를 한 번에 저장한다. 저장 실패 시 보유·육성 연결·레벨·알 상태를 되돌리고 기존 알을 유지한다.

커먼·레어·에픽·레전더리는 PokéRogue 알 프레임을 사용하고, 이로치알은 내장된 전용 이미지를 사용한다. 알 이미지 로드 실패 시 기본 타원형 알을 표시하며, 균열 에셋 로드 실패 시 균열 없이 부화를 진행한다. 등급별 즉시 지급은 Debug 빌드 전용이다.

## 이로치알 외형과 반짝임

- 이로치알 본체는 `Assets/shiny-egg.png`의 28×30픽셀 원본을 사용한다. 픽셀·색상·투명도를 유지하며 화면에서는 기존 알처럼 2배로 표시한다.
- 반짝임은 본체와 별도 이미지로 겹쳐 표시한다. 12프레임을 100ms 간격으로 전환해 1.2초 주기로 반복한다.
- `PendingEgg.Kind`가 `Shiny`인 알의 대기·준비 상태에서만 반짝인다. 부화 시작과 결과 상태에서는 즉시 숨긴다.
- 다른 네 등급에서 이로치가 확정돼도 반짝이지 않는다. Debug의 확정 이로치 옵션도 동일하다.
- 알 교체 시 기존 반짝임을 제거한다. 반짝임 로드가 실패해도 알 본체는 표시한다.
- 자산 규격과 로딩 방식은 [08-assets.md](08-assets.md)를 따른다.

## 중복과 색상 처리

- 일반 미보유 종을 일반으로 부화하면 일반 도감에 새로 등록한다.
- 중복 부화는 부화 직전 육성 상태로 레벨 보너스 또는 새 육성을 결정한다. 보너스로 진화 레벨에 도달해도 같은 부화에서 초기화하지 않는다.
- 일반으로 보유했더라도 같은 종의 이로치를 처음 부화하면 이로치 도감에서는 신규다.
- 이로치도 독립적인 분기 수집 이력을 기준으로 같은 중복 규칙을 적용한다.
- 레벨 보너스는 기존 경험치를 유지한다. 새 육성 시작은 경험치 0이며 기존 진화체의 성장에는 영향을 주지 않는다. 모든 분기를 획득했으면 이후 중복은 레벨 보너스다.
- 새 육성도 부화만으로 자동 선택하지 않는다. 해당 기본형을 이미 선택 중이었다면 표시 레벨이 새 기록으로 갱신된다.
- 상세 상태 전이는 [11-evolution.md](11-evolution.md)를 따른다.

이로치 획득과 표시 규칙은 [10-shiny.md](10-shiny.md)를 참고한다.
