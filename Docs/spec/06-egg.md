# 알 지급 및 부화

### 지급 규칙

- 다음 알까지 앱 실행 시간 **30분**을 누적한다. 대기 중 말풍선에 남은 시간을 `mm:ss`로 표시한다.
- 앱이 꺼진 동안에는 시간이 흐르지 않는다. 1초 주기로 실제 경과 시간을 더하되 절전 등으로 틱이 지연돼도 한 번에 최대 5초만 인정한다.
- 알은 한 번에 최대 1개만 보유한다. 알을 보유한 동안 타이머는 멈추며, 부화 후 다음 30분 누적을 시작한다.
- 알이 준비되면 말풍선에 **클릭하여 부화**가 표시된다. 준비 전 클릭은 부화를 시작하지 않는다.

### 부화 결과

1. 준비된 알을 클릭하면 흔들림, 균열, 플래시 애니메이션을 재생한다.
2. 진화 전 단계이거나 진화하지 않는 종을 담은 `BaseSpecies.Dex`에서 한 종을 뽑는다. 각 종의 확률은 `해당 종의 포획률 / 후보 전체의 포획률 합`이다. 후보와 포획률 데이터는 코드에 내장되어 있다.
3. 새 종이면 도감에 등록하고 **NEW!**를 표시한다. 이미 보유한 종이면 해당 종의 레벨을 1 올리고 `Lv.n ↑`를 표시한다. 중복 부화 시 기존 경험치는 유지된다.
4. 결과 아이콘과 이름을 약 5초간 보여준 뒤 다시 대기 상태로 돌아간다. 결과 아이콘 로드가 실패해도 이름은 표시한다.
5. 부화 결과와 알 소비 상태는 즉시 저장한다.

알 이미지나 균열 에셋을 가져오지 못하면 기본 타원형 알을 사용하고 균열 없이 부화를 진행한다. 우클릭 메뉴의 **알 즉시 획득(테스트)**은 일반 빌드에서도 노출되며, 부화 애니메이션이나 결과 표시 중이 아닐 때 알을 즉시 준비 상태로 만든다.
