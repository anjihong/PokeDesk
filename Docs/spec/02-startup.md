# 시작 및 스타팅 선택

## 시작 순서

1. `%LOCALAPPDATA%\DeskPokemon\settings.json`을 읽는다.
2. 유효한 저장 데이터가 있으면 마지막 `SelectedDex`와 `SelectedShiny`를 복원하고 메인 창을 연다.
3. 파일이 없거나 JSON을 해석할 수 없으면 스타팅 선택 창을 연다.
4. 스타팅 창에서 후보 하나를 선택하면 새 저장 데이터를 만든 뒤 메인 창을 연다.
5. 스타팅 창의 닫기 버튼을 누르면 새 데이터를 만들지 않고 앱을 종료한다.

## 스타팅 후보

풀·불꽃·물 목록에서 각각 한 종을 독립적으로 무작위 선택한다. 세 후보가 같은 세대일 필요는 없다.

## 새 게임 초기값

- 선택 종을 `StarterDex`, `SelectedDex`, 일반 `Owned`에 기록한다.
- 스타팅은 일반 개체이며 `SelectedShiny`는 `false`다.
- 스타팅 레벨은 1, 경험치는 0이다.
- 다음 알의 등급·종·이로치 여부를 즉시 확정해 `PendingEgg`로 저장한다.
- 알 보유 수는 0이며 30분 대기 시간은 0초부터 시작한다.

## 오류와 호환성

- 구버전 저장 데이터는 현재 스키마로 변환한 뒤 사용한다.
- 스타팅 번호가 없거나 전국도감 범위를 벗어나면 파이리 `#4`로 보정한다.
- 저장 데이터가 현재 앱보다 새 스키마면 원본을 수정하지 않는다. 오류 메시지를 표시하고 종료한다.
- 새 게임 파일을 만들지 못하면 오류 메시지를 표시하고 종료한다.
