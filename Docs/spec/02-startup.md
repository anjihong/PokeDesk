# 시작 및 스타팅 선택

1. 시작 시 `%LOCALAPPDATA%\DeskPokemon\settings.json`을 읽는다.
2. 저장 파일이 없거나 JSON을 읽을 수 없으면 스타팅 선택 창을 연다. 창을 닫거나 선택을 취소하면 앱을 종료한다.
3. 풀·불꽃·물 타입별로 1~9세대 스타팅 후보 중 각 1종을 무작위로 보여준다. 후보 카드에는 아이콘, 한글 이름, 타입이 표시된다. 아이콘을 가져오지 못해도 이름과 타입으로 선택할 수 있다.
4. 선택한 포켓몬을 `StarterDex`와 `SelectedDex`에 기록하고, 최초 보유 종으로 등록한 뒤 저장한다.
5. 기존 저장 파일은 스타팅 선택 창을 건너뛰고 마지막으로 선택한 포켓몬을 표시한다.

스타팅 후보 목록은 `Settings.RollStarterChoices()`에 있다. 예전 저장 파일에 스타팅 번호가 없다면 파이리(`#4`)로 보정한다.
