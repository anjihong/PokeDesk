# 스프라이트와 데이터 자산

## 다운로드와 캐시

- 포켓몬 본체, 도감 아이콘과 알 이미지는 실행 파일에 포함하지 않는다.
- 필요할 때 `pagefaultgames/pokerogue-assets` 또는 PokeAPI 저장소에서 다운로드한다.
- 다운로드 파일은 `%LOCALAPPDATA%\DeskPokemon\sprites` 아래에 원격 경로 구조를 유지해 저장한다.
- 같은 파일 요청은 진행 중 다운로드 작업을 공유한다. 이미 캐시된 파일은 다시 받지 않는다.
- 기본 HTTP 제한 시간은 10초다. 다운로드 실패는 호출 기능의 대체 표시 또는 오류 처리로 전달한다.

## 본체 스프라이트

- 일반 본체 스프라이트는 `pokemon/exp/`, `pokemon/` 순서로 첫 아틀라스를 찾는다. 이로치는 `pokemon/exp/shiny/`, `pokemon/shiny/` 순서로 찾는다.
- 찾은 아틀라스가 여러 프레임이면 즉시 사용한다. 정지 프레임이면 같은 색상의 PokeAPI 5세대 BW 스타일 GIF를 시도하고, GIF가 없으면 찾았던 정지 아틀라스를 사용한다.
- 이로치 아틀라스와 GIF가 모두 없을 때만 PokeAPI 이로치 정지 PNG를 마지막으로 시도한다. 일반과 이로치 사이의 색상 대체는 하지 않는다.
- GIF는 프레임 합성과 잘라내기를 거쳐 앱의 10fps 재생 간격에 맞춘다.

| 조건 | 결과 |
| --- | --- |
| 확장 또는 기본 아틀라스가 여러 프레임 | 해당 아틀라스 사용 |
| 찾은 아틀라스가 정지이고 같은 색상 GIF가 있음 | GIF 사용 |
| 찾은 아틀라스가 정지이고 GIF가 없음 | 찾았던 정지 아틀라스 사용 |
| 이로치 아틀라스가 없고 이로치 GIF도 없음 | PokeAPI 이로치 정지 PNG 사용 |
| 모든 같은 색상 소스가 없음 | 로드 실패 |

## 도감 아이콘

- 세대별 `pokemon_icons_{gen}.json`과 PNG 한 쌍을 사용한다.
- 같은 시트에 든 일반·이로치 프레임을 한 번 디코딩해 각각 캐시한다.
- 기본형 프레임만 사용한다. 폼 이름이 필요한 종은 `PokemonForms`의 기본 폼 매핑을 적용한다.
- 미보유 실루엣은 원본 알파를 유지하고 RGB만 어둡게 바꿔 메모리에 캐시한다.

## 알과 내장 데이터

- 알 외형은 PokéRogue의 커먼·레어·에픽·레전더리·마나피 알 프레임을 사용하며, 마나피 알 프레임을 이로치알 외형으로 사용한다.
- 한글 이름은 `PokemonNames`, 부화 후보는 `BaseSpecies`, 특수 종 분류는 `PokemonRarity`에 내장되어 있다. `CaptureRates` 데이터는 남아 있지만 현재 알 추첨에는 사용하지 않는다.

알 이미지는 부화 균열 효과와 맞도록 비율을 유지한 채 `28×30px` 영역 아래쪽 중앙에 정렬한다. 알 아트를 불러오지 못하면 기본 타원형을 표시한다.

## 로컬 UI 자산

- `Assets/PixelUI`에는 새 픽셀 UI 부품과 Galmuri 폰트가 준비되어 있고 프로젝트 리소스로 포함된다. **현재 메인/스타팅 화면 XAML은 이 부품을 사용하지 않는다.** 현재 화면은 WPF 도형·텍스트·스타일로 구성되어 있다. `design/`의 시안과 생성 스크립트도 런타임 기능이 아니다.

에셋 출처 및 라이선스 상세는 프로젝트 루트의 `README.md`를 따른다.
