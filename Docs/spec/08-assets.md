# 스프라이트와 데이터 자산

## 공통 픽셀 UI 경계

- `design/reference-ui-target.png`의 형태를 코드로 그린 `Assets/PixelUI` 부품을 사용한다. 생성기는 `design/draw_reference_pixel_ui.py`다.
- `PixelSurface`는 2px 자산 격자를 1 DIP로 배치하고 최근접 보간과 레이아웃 반올림을 직접 설정한다. 별도 시각 루트인 세대 팝업과 대화상자에서도 보간된 흐린 선이 생기지 않게 한다.
- 상세 패널과 안내 대화상자는 8 DIP 모서리를 고정하여 외곽뿐 아니라 안쪽 밝은 선도 늘어나지 않게 한다. 중앙 영역만 늘리며 바깥 윤곽에는 곡선형 둥근 모서리를 덧씌우지 않는다.
- 메인 화면은 `tab_rail.png`를 배경으로 그리지 않는다. 세 탭 행은 폭 344 DIP로 352 DIP 서랍의 양옆에서 4 DIP씩 들어간다. 탭 색상 면의 왼쪽 3 DIP·오른쪽 2 DIP 테두리까지 고려해, 서랍의 크림색 면이 시작하는 왼쪽 7 DIP·오른쪽 6 DIP 안쪽 경계에 맞춘다. `tab_rail.png`는 참고 조립용 자산으로만 남긴다.
- 탭 아래의 별도 색상 장식선은 제거하고, 도구막대와 목록은 하나의 짙은 3 DIP 경계로 연결한다. 목록과 상세 영역 사이의 크림색 간격은 참고 이미지대로 유지한다.

## 다운로드와 캐시

- 포켓몬 본체, 도감 아이콘과 커먼·레어·에픽·레전더리 알 이미지는 실행 시 다운로드한다. 이로치알과 반짝임은 앱에 포함한 PNG를 사용한다.
- 필요할 때 `pagefaultgames/pokerogue-assets` 또는 PokeAPI 저장소에서 다운로드한다.
- 다운로드 파일은 Windows의 `%LOCALAPPDATA%\DeskPokemon\sprites`, macOS의 `~/Library/Application Support/DeskPokemon/sprites` 아래에 원격 경로 구조를 유지해 저장한다.
- 같은 파일 요청은 진행 중 다운로드 작업을 공유한다. 이미 캐시된 파일은 다시 받지 않는다.
- 기본 HTTP 제한 시간은 10초다. 다운로드는 임시 파일을 거쳐 캐시에 반영하며, 실패한 요청은 이후 다시 시도할 수 있다. 다운로드 실패는 호출 기능의 대체 표시 또는 오류 처리로 전달한다.

## 본체 스프라이트

- 일반 본체 스프라이트는 `pokemon/exp/`, `pokemon/` 순서로 첫 아틀라스를 찾는다. 이로치는 `pokemon/exp/shiny/`, `pokemon/shiny/` 순서로 찾는다.
- 찾은 아틀라스가 여러 프레임이면 즉시 사용한다. 전국도감 기본종의 정지 프레임이면 같은 색상의 PokeAPI 5세대 BW 스타일 GIF를 시도하고, GIF가 없으면 찾았던 정지 아틀라스를 사용한다.
- 이로치 아틀라스와 GIF가 모두 없을 때만 PokeAPI 이로치 정지 PNG를 마지막으로 시도한다. 일반과 이로치 사이의 색상 대체는 하지 않는다.
- 지역 모습 11종은 `EvolutionData`의 내부 ID와 스프라이트 키를 사용한다. 내부 ID는 PokeAPI 번호가 아니므로 GIF·대체 PNG를 요청하지 않고 같은 지역 모습의 정지 아틀라스를 유지한다. 해당 모습의 아틀라스가 없으면 실패하며 기본형으로 바꾸지 않는다.
- GIF는 프레임 합성과 잘라내기를 거쳐 앱의 10fps 재생 간격에 맞춘다.
- PNG 아틀라스·GIF·대체 정지 이미지 모두 로드할 때 투명 여백을 제외한 몸체 경계와 발 기준점을 계산한다. 빈 프레임은 몸체 합집합에서 제외한다. 이 메타데이터는 [표시 규칙](03-pet-display.md)에 따라 종별 표시 크기와 그림자 위 발 위치 계산에 함께 사용한다.

| 조건 | 결과 |
| --- | --- |
| 확장 또는 기본 아틀라스가 여러 프레임 | 해당 아틀라스 사용 |
| 기본종의 아틀라스가 정지이고 같은 색상 GIF가 있음 | GIF 사용 |
| 기본종의 아틀라스가 정지이고 GIF가 없음 | 찾았던 정지 아틀라스 사용 |
| 기본종의 이로치 아틀라스가 없고 이로치 GIF도 없음 | PokeAPI 이로치 정지 PNG 사용 |
| 지역 모습의 아틀라스가 정지 | 같은 지역 모습의 정지 아틀라스 사용 |
| 모든 같은 색상 소스가 없음 | 로드 실패 |

## 도감 아이콘

- 세대별 `pokemon_icons_{gen}.json`과 PNG 한 쌍을 사용한다.
- 같은 시트에 든 일반·이로치 프레임을 한 번 디코딩해 각각 캐시한다.
- 기본형과 지역 모습 카탈로그의 프레임을 사용한다. 폼 이름이 필요한 기본종은 `PokemonForms`의 매핑을, 지역 모습은 `EvolutionData.Form`의 스프라이트 키·한글 이름을 사용한다.
- `PokemonIcons.Entries(gen)`는 해당 세대의 기본종 뒤에 지역 모습 ID를 추가한다. 8세대 지역 모습 10종과 9세대 1종을 포함해 전체 1,036개이며, 지역 모습의 일반·이로치 아이콘도 별도로 캐시한다.
- 미보유 실루엣은 원본 알파를 유지하고 RGB만 어둡게 바꿔 메모리에 캐시한다.
- 누락된 프레임은 다른 색상으로 대체하지 않는다. 도감 UI는 해당 번호의 `?` 셀을 유지하며, 세대 로드 실패에는 다시 시도를 제공한다.

## 알과 내장 데이터

- 커먼·레어·에픽·레전더리는 PokéRogue의 `egg_0`~`egg_3` 프레임을 사용한다.
- 이로치알은 main의 `Assets/shiny-egg.png`를 원본 28×30 픽셀 그대로 사용한다. `EggArtwork`의 버전 `2` 리소스 정의로 로드하며 `egg_manaphy`로 대체하거나 외부 다운로드하지 않는다.
- `Assets/shiny-egg-sparkles.png`는 480×38 수평 시트다. 리사이즈나 색 변경 없이 40×38 프레임 12개로 나눠 대기·준비 상태에서 100ms마다 재생한다. 알 기준 `(-6, -6)`에 겹쳐 최근접 보간으로 알과 함께 확대하며 클릭 판정에는 참여하지 않는다.
- 두 PNG는 `AvaloniaResource`로 포함해 Windows/macOS에서 동일하게 사용한다. 본체와 반짝임 로드는 독립적으로 처리하므로 효과 실패가 알 본체를 숨기지 않는다.
- 알 옆 말풍선에는 대기 시간 또는 부화 안내를 실제 텍스트로 표시하며 등급 이름을 이미지에 새기지 않는다. 알과 말풍선의 툴팁에 등급 이름을 제공하고 상태별 글자 크기는 [알 명세](06-egg.md)를 따른다.
- 알과 반짝임 프레임은 앱 수명 메모리 캐시가 소유한다. 표시하는 창은 프레임을 빌려 사용하며 직접 `Dispose`하지 않는다. 창 종료 시 효과 타이머·이벤트와 화면 참조만 정리한다.
- 기본종 한글 이름은 `PokemonNames`, 지역 모습 이름은 `EvolutionData.Forms`에서 읽는다. `BaseSpecies`는 `EvolutionData.EggPool`의 550개 부화 후보를 사용하고, 특수 종 분류는 `PokemonRarity`에 내장되어 있다. 이브이 진화형 8종은 새 알 후보에서 제외한다. `CaptureRates` 데이터는 남아 있지만 현재 알 추첨에는 사용하지 않는다.

다운로드한 알 이미지는 부화 균열 효과와 맞도록 비율을 유지한 채 `28×30px` 영역 아래쪽 중앙에 정렬한다. 내장 이로치알은 이미 같은 크기이므로 원본 픽셀을 유지한다. 알 아트를 불러오지 못하면 기본 타원형을 표시한다.

## 로컬 UI 자산

- `Assets/PixelUI`의 프레임, 탭, 셀, 체크박스, 경험치 표시 등의 PNG를 메인·스타팅 화면의 공통 Avalonia 스타일에서 사용한다. Windows와 macOS가 같은 리소스와 레이아웃을 사용한다.
- `PixelSurface`는 모서리를 유지하는 9분할 방식으로 패널을 그린다. 비트맵에는 최근접 보간을 적용하고, 기본 2px 자산 격자를 1 DIP로 배치한 뒤 전체 UI 배율을 적용한다.
- 폰트 버전은 Galmuri v2.40.4다. 본문은 Galmuri11과 Galmuri11-Bold, 보조 텍스트는 Galmuri9를 앱에 포함해 사용한다. 플랫폼의 기본 한글 폰트에 의존하지 않는다.
- PNG 32개는 `design/draw_reference_pixel_ui.py`가 참고 화면의 테두리와 색을 바탕으로 빈 캔버스에 그린 자산이다. PNG에는 글자나 포켓몬이 포함되지 않는다. [자산 README](../../Assets/PixelUI/README.md)에 생성 방법과 레이어를 기록한다.
- `design/`의 조립 미리보기는 제작 자료다. 실행 시에는 분리된 PNG와 실제 앱 텍스트·포켓몬 그림을 합성한다.

## 진화·한글 타입·설명·종별 높이 데이터

- `Assets/Data`의 JSON을 앱 리소스로 포함하고 `EvolutionData`, `PokemonDetails`, `PokemonDisplaySize`에서 읽는다. 실행 중 도감 설명·진화 조건·종별 높이를 다운로드하지 않는다.
- 데이터 원본은 PokeAPI 저장소의 고정 커밋 `168b1e89467054cda2e7df43ccebbb69b459497a`다. 입력 CSV별 SHA-256, 변환 규칙과 설명 대체 대상은 [`sources.json`](../../Assets/Data/sources.json)에 기록한다.
- 전국도감 기본 1,025종과 지역 모습 11개, 총 1,036개 모습의 타입·설명과 486개 직접 진화 규칙, 550개 알 후보를 제공한다. 지역 모습은 별도 내부 ID·전국도감 번호·세대·한글 이름·스프라이트 키를 가진다. 원본에 있는 한글 도감 문장은 버전 ID 기준 최신 항목을 사용하고 줄바꿈을 정리한다.
- 원본에 한글 도감 문장이 없는 `#899~#1025` 127종과 지역 모습 11개는 출처의 한글 분류·해당 모습의 실제 타입으로 설명을 구성한다. 이 138개 항목은 `MetadataOnly`로 구분하며 새 도감 문장을 창작하거나 다른 언어를 임의 번역하지 않는다. 나머지 898종은 출처의 한글 도감 문장을 사용한다.
- 진화·타입·설명 카탈로그 갱신은 `python3 scripts/generate-pokemon-data.py --download`로 수행한다. 이미 받은 고정 CSV를 사용하려면 `--source-dir /path/to/csv`를 지정한다. 원본 고정값·해시·생성 결과를 함께 검토한다.
- 종별 높이는 같은 고정 커밋의 `pokemon.csv`에서 데시미터 단위로 가져온다. `pokemon-sizes.json`은 기본종과 지역 모습 전체 1,036개 높이, 출처 커밋과 단위를 포함한다. `PokemonDisplaySize`가 이를 72~100 DIP의 목표 몸체 높이로 압축하며 수식과 발 배치 규칙은 [표시 명세](03-pet-display.md)를 따른다.
- 크기 데이터는 별도 명령 `python3 scripts/generate-pokemon-sizes.py --source-dir /path/to/csv`로 재생성한다. 앞서 사용한 것과 동일한 고정 CSV 폴더를 지정하며, 생성기는 `sources.json`에 기록된 `pokemon.csv`의 SHA-256을 확인한 뒤 출력한다.
- 앱에 맞춘 진화 조건과 이브이 예외는 [11-evolution.md](11-evolution.md)에 기록한다.
