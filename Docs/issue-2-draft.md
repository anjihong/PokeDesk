# 진화·지역 모습·분기 재육성 구현

## 현재 상태

2026-09-28 로컬 작업 코드 확인 기준, 진화 기능은 아직 구현되지 않았습니다. 데이터·아트 조사와 구현 계획을 확정한 상태입니다.

- 현재 도감은 기본 모습 1,025종이며, 일반·이로치 성장과 보유를 분리합니다.
- 현재 중복 부화는 경험치를 유지하고 해당 포켓몬의 레벨을 1 올립니다.
- 현재 저장 스키마는 2입니다. 아래 진화·지역 모습·재육성 규칙과 스키마 3은 구현 예정입니다.
- 관련 문서: `Docs/spec/11-evolution.md`. 현재 로컬 조사 초안이며, 구현 시작 시 아래 확정 명세로 갱신합니다.

## 1. 진화 기준

- 원작의 진화 관계를 유지하고 모든 조건을 레벨로 통일합니다.
- 원작의 고정 진화 레벨이 있으면 해당 값을 적용합니다.
- 고정 레벨이 없으면 첫 진화는 **25**, 두 번째 진화는 **40**을 적용합니다. 친밀도 진화도 최소 레벨이 없으면 같은 대체값을 사용합니다.
- 진화 판정은 `현재 레벨 >= 필요 레벨`입니다. 시간대·성별·아이템·교환 등 추가 조건은 레벨 조건으로 대체하되, 지역 모습별 진화 관계는 유지합니다.
- 다음 분기는 모든 대상의 레벨을 통일합니다.

| 분기 시작 | 진화 대상 | 적용 레벨 |
| --- | --- | ---: |
| 야돈 | 야도란·야도킹 | 37 |
| 킬리아 | 가디안·엘레이드 | 30 |
| 토중몬 | 아이스크·껍질몬 | 20 |
| 눈꼬마 | 얼음귀신·눈여아 | 42 |

- 토중몬의 껍질몬은 이 게임에서 별도의 분기 대상으로 처리합니다.
- 첫 분기 진화는 대상 중 균등 무작위로 하나를 획득합니다.
- 재육성에서는 아직 획득하지 않은 분기 대상을 직접 선택합니다. 남은 대상이 하나면 자동 결정합니다.
- 일반·이로치는 성장과 분기 수집 이력을 분리합니다.
- 이브이는 진화하지 않습니다. 이브이와 진화체 8종은 알에서 독립적으로 획득·육성합니다.

## 2. 지역 모습과 데이터

기존 도감에 아래 **11개 모습**을 별도 칸으로 추가합니다. 수집 대상은 **1,036개**이며 일반·이로치 도감에 각각 적용합니다.

| 구분 | 추가 모습 |
| --- | --- |
| 가라르 | 지그제구리, 직구리, 나옹, 코산호, 파오리, 마임맨, 데스마스 |
| 히스이 | 포푸니, 침바루 |
| 팔데아 | 우파 |
| 특수 모습 | 흰줄무늬 배쓰나이 |

- 일반 모습과 별도 보유·선택·성장 대상으로 취급합니다. 추가 모습은 등장 세대인 8·9세대에 표시합니다.
- 가라르 지그제구리는 가라르 직구리, 가로막구리 순서로 진화합니다.
- 흉내내는 일반·가라르 마임맨으로 분기하며 두 대상 모두 25레벨을 적용합니다. 가라르 마임맨은 42레벨에 마임꽁꽁으로 진화합니다.
- 가라르 나옹은 나이킹, 코산호는 산호르곤, 파오리는 창파나이트, 데스마스는 데스판으로 진화합니다.
- 히스이 포푸니는 포푸니크, 침바루는 장침바루로 진화합니다.
- 팔데아 우파는 토오, 흰줄무늬 배쓰나이는 대쓰여너로 진화합니다.
- 일반 모습에 지역 모습 전용 진화체를 연결하지 않습니다.
- 추가 계열의 기본형을 알 후보에 넣습니다. 가라르 직구리·마임맨은 진화로 획득합니다.
- 알 등급과 이로치 확률은 유지합니다. 알 후보 변경은 추첨과 저장 검증에 함께 적용합니다.

## 3. 분기 재육성과 중복 부화

성장은 **육성 기록 단위**로 공유합니다. 한 육성에서 거친 모습들은 같은 레벨·경험치를 사용하지만, 새 육성은 기존 분기 진화체와 독립됩니다.

| 부화 직전 상태 | 같은 기본형이 부화한 결과 |
| --- | --- |
| 해당 색상의 첫 획득 | Lv.1, 경험치 0 |
| 이번 육성의 분기 진화 미완료 | 기존 레벨 +1, 경험치 유지 |
| 이번 육성의 분기 진화 완료·미수집 분기 있음 | 새 육성을 Lv.1, 경험치 0으로 시작 |
| 모든 분기 획득 완료 | 기존 레벨 +1, 경험치 유지 |
| 분기 없는 계열의 중복 | 기존 레벨 +1, 경험치 유지 |

레벨 보너스로 진화 조건에 도달하면 먼저 보너스를 지급한 뒤 진화를 판정합니다. 같은 부화에서 다시 Lv.1로 초기화하지 않습니다.

### 예시: 랄토스 계열

1. 랄토스를 키워 킬리아를 거쳐 첫 무작위 진화로 가디안을 획득합니다.
2. 랄토스가 다시 부화하면 새 랄토스는 Lv.1이 됩니다. 기존 가디안의 성장은 보존합니다.
3. 새 랄토스가 킬리아로 진화하면 두 모습이 새 육성의 성장을 공유합니다.
4. Lv.30에 남은 엘레이드를 획득합니다.
5. 이후 랄토스 중복 부화는 레벨 보너스로 처리합니다.

- 도감은 모습당 한 칸을 유지하며 동일 모습의 여러 개체를 고르는 인벤토리는 추가하지 않습니다.
- 기본형 칸은 새 육성을 가리킵니다. 중간 모습 칸은 새 육성이 해당 모습에 도달했을 때 새 기록으로 연결합니다.
- 기존 분기 진화체는 이전 기록으로 계속 독립 성장합니다.
- 개무소처럼 분기 후 진화가 이어지는 계열도 이전 육성의 실쿤·뷰티플라이와 새 육성의 카스쿤·독케일을 분리합니다.
- 분기 완료는 직접 분기 대상의 획득 기준입니다.
- 계정 보유 여부와 이번 육성의 진화 이력을 구분해 이미 도감에 있는 중간 모습으로도 다시 진화할 수 있게 합니다.

## 4. 진화 화면과 선택

- 입력 레벨업, 중복 부화, 선택 변경, 저장 불러오기에서 진화 가능 여부를 갱신합니다.
- 현재 모습이 진화할 단계면 진화를 시작하고, 짧은 점멸 연출 후 진화체를 자동 선택합니다.
- 진화 전 모습도 도감에서 계속 선택할 수 있습니다.
- 이전 모습을 선택 중일 때 다음 진화 조건을 만족하면 머리 위에 **진화 가능**을 표시합니다.
- 도감에서는 진화를 시작할 모습과 해당 세대 탭을 강조합니다. 강조된 모습을 선택하면 진화가 시작됩니다.
- 예: 파이리를 선택한 채 공유 레벨이 36에 도달하면 리자드를 강조합니다. 리자드를 선택하면 리자몽으로 진화합니다.
- 재육성 후보가 여러 개면 선택창을 표시합니다. 선택창을 닫으면 진화 가능한 상태를 유지합니다.
- 여러 단계 조건을 충족했으면 한 단계씩 처리합니다.
- 부화 결과는 신규 획득·레벨 보너스·새 육성을 구분하며, 새 육성에는 **새 육성 · Lv.1**을 표시합니다.

## 5. 저장과 실패 처리

- `For()`는 모습에 연결된 육성 기록을 반환합니다. 진화 후보 계산과 확정은 `Settings`의 공통 처리로 모읍니다.
- 무작위 결과는 진화 시작 시 확정·저장합니다. 이미지 로드 실패나 재시작으로 다시 추첨하지 않습니다.
- 진화·부화 저장 실패 시 성장·보유·선택·알 상태를 복원합니다.
- 비동기 로드 중 다른 선택이 들어오면 오래된 요청이 최종 화면을 덮어쓰지 않게 합니다.
- 저장 스키마를 **3**으로 올립니다. 기존 종별 성장은 독립 육성 기록으로 그대로 이전하고 이후 실제 진화부터 성장 공유를 적용합니다.
- 기존 선택·일반/이로치 보유·확정 알을 보존하며 기존 백업·원자적 저장 방식을 유지합니다.
- Debug 전체 해금은 실제 보유나 분기 수집 완료로 취급하지 않습니다.
