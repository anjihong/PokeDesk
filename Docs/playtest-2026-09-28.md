# 2026-09-28 Avalonia 기능·실제 Mac 플레이 확인

대상은 `feat/11-macos-avalonia`의 진화·설정·픽셀 UI·혼합 도감 변경이다. 멀티플레이 #1은 사용자 요청으로 제외했다. Windows `main`에는 적용하지 않는다.

## 자동 검증

- Release와 Debug의 `DeskPokemon.Tests`: 각각 188개 통과.
- 스크린샷 비교 스크립트 회귀 테스트: 9개 통과. 기존 픽셀 비교 허용치를 유지한다.
- 일반·이로치 진화, 이전 형태 유지, 분기 선택, 이미지 실패, 원자적 저장 실패 복구와 재실행 데이터 복원을 포함한다.
- 일반 4·5·6번을 서로 다른 레벨/경험치로 보유한 상태에서 이로치 4→5→6으로 진화해도 일반 목록·성장이 그대로임을 검사한다. 진화 이미지 요청의 `shiny/` 경로와 저장 후 복원도 확인한다.
- 혼합 도감, 이로치만 필터, 빠른 전환, 부화/진화의 새 칸 추가, ★ 배지, 2·8배 정렬과 긴 이름/타입을 검증한다.
- Windows x64·Mac ARM64·Mac x64 CI는 공통 화면 24개 PNG와 레이아웃 기록을 비교한다. CI 결과는 해당 커밋의 `Windows and macOS` 워크플로 실행에서 확인한다.

## 실제 Mac 플레이

환경: macOS 26.6.2 / ARM64, Avalonia `RenderScaling=2`, `DesktopScaling=1`. 실행 중 전역 입력 훅은 `Active`였다.

[네이티브 플레이 도구](../Tests/DeskPokemon.NativePlay/README.md)를 Release로 실행했다. 실제 macOS 창에 CGEvent 마우스·키보드 이벤트를 보내고 실제 다운로드/캐시 이미지로 확인했다. 진화 레벨과 준비된 알은 메모리 전용 테스트 데이터에 설정했다.

확인한 동작:

- 경험치 바 실제 hover로 현재/필요 경험치 표시.
- 키 자동 반복을 포함한 한 번 누름이 경험치 1회만 증가.
- 설정 탭에서 반전, 2→4→2배, 자동 시작 체크박스 켜기/끄기.
- 전체 1,025종과 보유 이로치 추가 칸, 기본 보유 목록의 일반/이로치 동시 표시, 이로치만 필터, 별도 성장 표시.
- 일반 파이리→리자드 진화 후 이전 파이리 선택, 성장한 조상 조건으로 리자드→리자몽 진화.
- **이로치 파이리→이로치 리자드→이로치 리자몽** 진화. 세 이로치 형태 보유와 ★ 표시, 일반 목록·레벨·경험치 불변 확인.
- 준비된 알 클릭 후 이로치 꼬부기 획득, 결과 이미지, 알 한 개 소비와 다음 알 준비.
- 진화·부화 후에도 도감 열기 X 좌표 유지와 닫기 시 원래 위치 복귀.
- 실제 플레이어 저장 파일의 실행 전후 SHA-256 일치.

최종 실행은 `NATIVE_PLAY_PASS`로 종료했다. `artifacts/native-play/play.log`와 같은 폴더의 8개 PNG에 기록했다. PNG는 실제 창의 Avalonia 렌더 결과이며 OS 합성 화면 캡처가 아니다. 이전 실행 한 번은 hover 대기 시간이 초과되어 재실행했으며, 최종 실행은 전체 흐름을 통과했다.

## 플레이 중 개선한 부분

- 좌우 반전이 몸체 확대 변환을 덮어쓰던 문제를 분리된 컨테이너로 수정.
- 진화 중 이전 종 이미지 재시도가 진화 후 모습을 덮는 경쟁 조건 차단.
- 열린 서랍에서 긴 오류/내용 변경 시 잘림을 없애고 최대 높이·스크롤·원점 복귀 유지.
- 알 타이머와 EXP 하단 정렬, 상세 타입과 구분선 겹침 제거, 보유 필터에서도 첫 열 정렬.
- 늘어난 버튼 양옆 회색 면, 체크박스 행 전체 윤곽선, 서랍 모서리 늘어남과 탭 사이 불필요한 틈 정리.

## 검증의 범위

Windows 실제 데스크톱 조작과 Mac Intel 실기 조작은 이 환경에서 수행하지 않았다. 해당 OS의 빌드·테스트·공통 UI 렌더 비교는 CI 결과와 구분한다. 자동 시작은 가짜 서비스와 임시 등록 파일/레지스트리 저장소를 검증했으며 실제 사용자 시작 항목 변경이나 로그아웃·로그인은 하지 않았다. 권한 최초 거부/승인과 모니터 간 DPI 전환은 [플랫폼 QA](cross-platform-qa.md)에 별도 확인 항목으로 남긴다.
