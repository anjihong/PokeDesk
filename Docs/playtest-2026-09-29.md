# 2026-09-29 종별 크기 및 main 업데이트 검증

대상은 `feat/11-macos-avalonia`다. Windows `main`의 `bcdb5a1` 이후 `78dc8cb`까지를 확인해 공통 Avalonia UI에 이식했다. 변경된 자산은 진화 카탈로그이며 PNG와 폰트의 추가 변경은 없었다. 이브이 8갈래 진화, 분기 재육성, 지역 모습 11개, 공유 성장 회차, 시작 화면 준비와 Debug 진화 도구를 반영했다. 멀티플레이는 보류한다.

## 표시 크기

종별 높이 데이터를 완만하게 압축한 92~120 DIP 목표 높이를 사용한다. 파이리·리자드·리자몽은 96·106·114 DIP이며 일반·이로치와 진화 연출에 같은 규칙을 적용한다. 발 정렬과 212 DIP 너비 제한은 유지한다. 자세한 규칙은 [표시 명세](spec/03-pet-display.md)를 따른다.

## 실제 Mac 플레이

macOS 26.6.2 / ARM64, `RenderScaling=2`, `DesktopScaling=1`, 전역 입력 훅 `Active`에서 [네이티브 플레이 도구](../Tests/DeskPokemon.NativePlay/README.md)를 Release로 실행해 `NATIVE_PLAY_PASS`를 확인했다. 메모리 전용 세이브와 가짜 자동 시작 서비스를 사용했고 실제 플레이어 저장 파일의 실행 전후 SHA-256은 일치했다.

- 실제 마우스 hover로 경험치 말풍선, 키 자동 반복 제외, 반전·배율 설정을 확인했다.
- 파이리 96, 리자드 106, 리자몽과 이로치 리자몽 114, 팔데아 우파 92 DIP를 확인했다. 각 발 기준점이 그림자의 실제 중심과 일치했다.
- 전체 1,036개 모습, 일반·보유 이로치 혼합 목록, 이로치만 필터와 상세 정보를 확인했다.
- 일반·이로치 파이리→리자드→리자몽 진화와 빛·실루엣·색상 공개 단계를 확인했다. 이로치 진화 후 일반 보유·성장·연결 정보는 그대로였다.
- 이전 모습의 안내를 클릭해 현재 진화 출발 모습의 세대 도감을 열고, 해당 모습을 선택해 이어서 진화했다.
- 이브이의 첫 무작위 분기와 중복 알 부화에 따른 Lv.1 재육성, 남은 7개 후보 중 다른 가지 진화를 확인했다. 기존 가지의 성장과 이로치 기록은 유지됐다.
- 팔데아 우파를 9세대에서 선택해 별도 이름·독/땅 타입·전국도감 번호 0194를 확인했다.
- 알 소비·결과 표시와 진화/부화 이후 도감 열기·닫기의 정확한 위치 복귀를 확인했다.

실행 로그는 `artifacts/native-play/play.log`, 이미지 기록은 같은 폴더의 PNG다. 이 PNG는 실제 창의 Avalonia 렌더 결과이며 OS 합성 화면 캡처는 아니다.

## 자동 검증과 개선

- 로컬 Release 전체 249개를 통과했다. Debug 전체 252개를 통과한 뒤 추가한 시작 중 레벨업 경계는 Release 전체 및 Debug 시작 화면 검사로 확인한다.
- 종별 크기 범위, 투명 여백·넓은 몸체·반전 후 발 배치와 진화 연출을 검사한다.
- 실제 캐시의 파이리 108·리자드 90·리자몽 144프레임(총 342프레임)을 공통 Skia headless 화면에서 추가 검사했다. 목표 높이 96·106·114 DIP와 전 프레임의 발·그림자 중심 거리 0 DIP를 확인했다. PNG와 측정값은 `artifacts/size-preview-20260929/`에 기록하며 실제 OS 창 검증과 구분한다.
- 기존 스키마 2의 독립 성장 보존, Windows main 스키마 3 호환, 예약 알 보존, 손상된 성장 연결 거부를 검사한다.
- 진화 예약 저장 실패, 완료 저장 실패, 종료 후 확정 대상 유지와 색상별 공유 성장 회차를 검사한다.
- 세대 탭의 선택 이벤트가 이전 탭 해제보다 먼저 발생해 옛 목록을 다시 읽던 문제를 수정했다. 8→9세대와 전체/보유/이로치 필터 전환을 회귀 검사한다.
- 시작 시 알 이미지가 늦게 준비되는 동안 레벨업하더라도, 준비와 진화 확인을 완료한 화면을 표시하도록 순서를 고쳤다.
- 스크린샷 비교기 회귀 테스트 9개를 통과했다. 기존 픽셀 허용치를 유지한다.

Windows x64와 Mac Intel의 실제 데스크톱 조작은 이 환경에서 수행하지 않았다. 세 OS의 빌드·전체 테스트·30개 공통 화면 비교는 해당 커밋의 `Windows and macOS` CI 결과로 확인하며, 실제 Mac 입력 검증과 구분한다.

## main 병합 기준 정리

main 우선 반영 요청에 따라 `origin/main`을 다시 확인했다. 최신 커밋은 이미 기능을 이식한 `78dc8cb`이며 추가 원격 커밋은 없었다. 이번에는 이 커밋을 실제 병합 부모로 기록해 다음 업데이트부터 새 변경만 비교할 수 있게 한다. 공통 Avalonia UI와 요청받은 호버·종별 크기·진화 연출은 유지한다.

- main의 진화 카탈로그, 알 규칙·등급, 이름·희귀도와 생성기 파일의 바이트 일치를 확인했다.
- 중복된 진화 생성 알고리즘을 제거하고 main의 `tools/generate_evolutions.py`를 직접 사용한다. 고정 CSV로 임시 폴더에 재생성한 진화·한글 상세·출처 JSON 3개가 기존 파일과 바이트 단위로 일치했다.
- main처럼 진화 테스트 모드에서 로컬 키·클릭 경험치를 차단했다. 실제 headless 클릭 1회와 키 재입력 2회의 회귀 테스트로 수정 전 테스트 모드의 3 XP 증가를 재현했다. 수정 후 일반 모드는 3 XP, 테스트 모드는 0 XP로 확인했다.
- 로컬 Debug 전체 261개와 Release 전체 255개가 통과했다. 실제 저장 파일을 사용하지 않았다. 이번 병합에서는 네이티브 데스크톱 플레이를 추가로 실행하지 않았다.
