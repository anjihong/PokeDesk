# 2026-10-07 참고 UI 및 픽셀 경계 검증

대상은 `feat/11-macos-avalonia`다. [#9 ART/UI](https://github.com/anjihong/PokeDesk/issues/9)의 예시 이미지는 저장소의 `design/reference-ui-target.png`와 동일했다. 공통 Avalonia 화면의 배치·부품·색상·글자 크기를 이 그림에 맞추고, 후속 요청에 따라 탭 뒤의 빨간 받침을 제거했다. GitHub 이슈와 main은 읽기만 했으며 원격 이슈·설정·브랜치를 변경하지 않았다.

## 변경된 화면

- 도감·박스·설정의 세 탭을 실제 기능에 연결했다. 박스는 보유한 일반·이로치를 함께 표시하고, 별 필터는 이로치만 남긴다. 도감으로 돌아오면 이전 보유 필터를 복원한다.
- 탭은 각각 116 DIP, 경계 겹침은 2 DIP다. 행의 양옆을 4 DIP씩 안으로 배치해 탭의 색 면과 하단 패널의 크림색 면이 같은 위치에서 시작하도록 맞췄다. 붉은 뒷판은 그리지 않는다.
- 세대 화살표와 전체/1~9세대 팝업, 6열×4행 목록, 밝은 미보유 칸과 청남색 실루엣, 하단 상세 패널을 구성했다. 목록은 휠로 스크롤되며 도구막대는 고정된다.
- 별 체크박스에 40 DIP와 양옆 간격을 확보했다. 보유 수는 최대 `2072/2072`까지 온전히 표시하고, 긴 본체 이름은 말줄임과 전체 이름 툴팁을 사용한다. 상세 설명은 두 줄과 전체 문장 툴팁을 제공한다.
- 속성 이름은 배지 가운데 정렬한다. 짧은 단일 속성은 최소 48 DIP 배지에서 좌우 여백을 균등하게 쓰고, 긴 복합 속성은 166 DIP 이내에서 내용에 맞춰 늘어난다.
- 패널을 늘려도 계단형 모서리·밝은 안쪽 선·외곽선 두께를 유지한다. 탭의 불필요한 아래 장식선을 제거하고 목록 위 경계를 하나로 정리했다.
- 참고 그림의 비율에 맞춰 종별 목표 높이를 72~100 DIP로 조정했다. 파이리·리자드·리자몽은 76·86·94 DIP이며 발 정렬·212 DIP 너비 제한·이로치 진화 규칙을 유지한다.
- main `5203416`의 이로치 알 PNG와 12프레임 반짝임을 Avalonia로 이식했다. 대기 말풍선은 시간만 표시하며, 등급은 알과 말풍선 툴팁에서 확인한다. 부화 결과가 다음 알의 카운트다운으로 덮이던 문제도 수정했다.

현재 동작은 [본체 표시](spec/03-pet-display.md), [도감](spec/05-pokedex.md), [알](spec/06-egg.md), [자산](spec/08-assets.md), [설정](spec/12-settings.md) 명세에 반영했다.

## 검증 방법

- 픽셀 비교는 2배 렌더링으로 수행한다. 원래 높이와 늘어난 상세 패널의 네 모서리, 너비가 바뀐 세 탭 자산의 계단형 어깨와 하단 모서리를 원본 PNG와 비교한다. 완전 투명 픽셀의 숨은 RGB만 정규화하고 나머지는 바이트가 같아야 통과한다.
- 배율 2/8의 실제 배치에서 탭 색 면 정렬, 별 글자 전체 영역, 최대 보유 수, 긴 지역 이름과 상세 정보, hover 중 고정된 클릭 영역을 검사한다.
- 세 탭·세대 화살표·팝업을 마우스와 키보드로 조작하며 필터·이로치 성장·설정 전환을 검사한다. 전체 회귀 테스트는 임시 또는 메모리 전용 저장 데이터를 사용한다.
- [NativePlay](../Tests/DeskPokemon.NativePlay/README.md)는 macOS 실제 창과 CGEvent를 사용한다. `--reference`는 실제 캐시 이미지로 도감·박스·설정 화면을 기록한다. PNG는 실제 창의 Avalonia 렌더 결과이며 OS 합성 화면 캡처는 아니다.

이번 환경은 macOS 26.6.2 / ARM64이며 네이티브 실행에서 `RenderScaling=2`, `DesktopScaling=1`, 전역 입력 훅 `Active`를 확인했다. 자동 시작은 가짜 서비스를 사용하고 실제 플레이어 저장 파일의 실행 전후 SHA-256을 비교한다. Windows와 Mac Intel의 실제 창 조작 및 새 원격 CI 실행은 이번 작업에서 수행하지 않았다.

## 실행 결과

- 로컬 Release 전체 **278/278**, Debug 전체 **284/284**를 통과했다.
- 이후 속성 배지의 가운데 정렬 요청을 반영하고, 영향받는 상세 헤더 테스트 **2/2**를 다시 통과했다. 2·8배에서 `물`, `불꽃`, `드래곤 · 에스퍼`의 실제 글자 폭과 배지 중심을 비교했다. 이 수정 후 참고 화면 모드도 다시 통과했다.
- 실제 Mac의 참고 화면 모드는 `NATIVE_REFERENCE_PASS`를 출력했다. 도감·박스·설정의 실제 클릭과 새 배치, 포켓몬 발 기준점, 자동 시작 미변경, 실제 플레이어 저장 파일 미변경을 확인했다.
- 실제 Mac 전체 플레이도 `NATIVE_PLAY_PASS`를 출력했다. 경험치 말풍선·전역 키 반복 제외·설정·전체/보유/이로치 필터, 일반·이로치의 두 단계 진화와 실루엣 연출, 부화, 이브이의 첫 분기와 재육성 후 다른 분기, 팔데아 우파 선택, 서랍 닫기 후 정확한 위치 복귀를 통과했다. 실제 플레이어 저장 파일은 변경되지 않았다.
- 네이티브 도구에서 새로 만든 도감 셀을 배치 전에 스크롤하려다 화면 밖을 누르던 문제를 수정했다. 배치와 서랍 이동 완료 후 `BringIntoView`를 요청하고, 창·스크롤 영역·모니터 안에 안정된 클릭점이 있을 때만 클릭한다. 전체 경험치 툴팁 검증은 실제 선택된 성장 회차의 현재 레벨·경험치를 비교한다.
