# Project instructions

- After adding or changing a feature or fixing a bug, update the relevant `Docs/spec/` files to match the implemented behavior before finishing the task. If no document covers the feature, add one and link it from `Docs/spec/01-overview.md`.
- When syncing main into the Avalonia branch, prioritize main's gameplay, data, and feature changes. Adapt WPF-specific code to the shared Windows/macOS Avalonia UI; preserve requested UI improvements unless they conflict with incoming main changes. Follow the sync guidance in `Docs/CONTRIBUTING.md`.
